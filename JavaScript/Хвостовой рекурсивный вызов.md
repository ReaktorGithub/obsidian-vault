Хвостовой рекурсивный вызов (tail recursion) в JavaScript - это рекурсивный вызов функции, который является последней операцией в функции. После его выполнения функции больше ничего не нужно делать.

## Пример

Обычная рекурсия:

```
function factorial(n) {
    if (n <= 1) return 1;

    return n * factorial(n - 1);
}
```

Вызов `factorial(n - 1)` не является хвостовым, потому что после его завершения нужно умножить результат на `n`.

Хвостовая рекурсия:

```
function factorial(n, acc = 1) {
    if (n <= 1) return acc;

    return factorial(n - 1, n * acc);
}

console.log(factorial(5)); // 120
```

Здесь `acc` - аккумулятор, в котором накапливается результат вычислений. Рекурсивный вызов сразу возвращается, и после него никаких операций не выполняется.

## Зачем нужна хвостовая рекурсия?

При обычной рекурсии каждый вызов должен сохранить контекст выполнения, чтобы продолжить работу после возврата из вложенного вызова. При хвостовой рекурсии теоретически можно не накапливать такие контексты, а переиспользовать текущий стек вызовов.

Это называется оптимизацией хвостовых вызовов (TCO, Tail Call Optimization).

Однако есть важный нюанс: JavaScript не гарантирует оптимизацию хвостовой рекурсии во всех движках. Хотя стандарт ECMAScript предусматривает proper tail calls при определённых условиях, на практике в популярных браузерах и Node.js рассчитывать на такую оптимизацию не стоит. Поэтому глубокая хвостовая рекурсия всё равно может привести к `Maximum call stack size exceeded`.

Коротко для собеседования: хвостовая рекурсия - это рекурсия, при которой рекурсивный вызов является последней операцией функции. Она позволяет реализовать алгоритмы так, чтобы потенциально избежать роста стека вызовов при наличии оптимизации TCO, но в JavaScript эта оптимизация практически не поддерживается распространёнными движками.
