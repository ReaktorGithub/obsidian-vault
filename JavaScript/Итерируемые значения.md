Итерируемые значения (iterables) в JavaScript - это значения, элементы которых можно последовательно перебирать, например с помощью цикла `for...of`.

Технически объект является итерируемым, если реализует метод `Symbol.iterator`.

## 1. Примеры итерируемых значений

```
const arr = [10, 20, 30];
const str = "Hello";
const set = new Set([1, 2, 3]);
const map = new Map([["name", "Oleg"]]);

for (const value of arr) console.log(value);
for (const char of str) console.log(char);
for (const value of set) console.log(value);
for (const entry of map) console.log(entry);
```

Все эти значения можно перебирать с помощью `for...of`.

## 2. Как это работает?

При выполнении `for...of` JavaScript вызывает метод `Symbol.iterator`, который возвращает итератор. Итератор последовательно выдаёт элементы через метод `next()`.

```
const iterable = {
  [Symbol.iterator]() {
    let i = 0;

    return {
      next() {
        return i < 3
          ? { value: i++, done: false }
          : { value: undefined, done: true };
      },
    };
  },
};

for (const value of iterable) {
  console.log(value); // 0, 1, 2
}
```

## 3. Итерируемые и неитерируемые значения

|Значение|Итерируемое?|
|---|---|
|`Array`|Да|
|`String`|Да|
|`Set`|Да|
|`Map`|Да|
|`NodeList`|Обычно да|
|Обычный объект `{}`|Нет, по умолчанию|
|`Number`|Нет|
|`Boolean`|Нет|

Обычный объект можно перебирать через `for...in`, поскольку этот цикл перебирает перечисляемые строковые ключи. Но это не делает объект итерируемым для `for...of`.

## 4. Где ещё используются итераторы?

Итерируемые значения можно использовать не только в `for...of`, но и в других конструкциях:

```
const numbers = [1, 2, 3];

console.log([...numbers]);       // [1, 2, 3]
console.log(Math.max(...numbers)); // 3

const [first, second] = numbers;
console.log(first, second); // 1 2
```

Здесь используются распространение (`...`) и деструктуризация, которые работают с итерируемыми значениями.

## Коротко для Obsidian

- Iterable (итерируемое значение) - объект, реализующий `Symbol.iterator` и позволяющий последовательно получать элементы.
    
- Iterator (итератор) - объект с методом `next()`, возвращающим `{ value, done }`.
    
- `for...of` перебирает значения итерируемого объекта.
    
- `for...in` перебирает перечисляемые строковые ключи объекта.
    
- Итерируемые значения используются в `for...of`, spread (`...`), деструктуризации и `Array.from()`.
