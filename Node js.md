В Node.js event loop имеет несколько фаз:

```
timers
   ↓
pending callbacks
   ↓
poll
   ↓
check
   ↓
close callbacks
```

Node.js использует движок V8 для выполнения JavaScript, а libuv предоставляет event loop и механизмы асинхронного I/O.
JavaScript выполняется в основном в одном потоке, поэтому Node.js не блокирует его во время большинства I/O-операций.
Event loop отслеживает завершение асинхронных операций и передаёт их callbacks на выполнение.
При этом некоторые тяжёлые или системные операции могут выполняться через thread pool. 
Главная особенность Node.js - эффективная работа с большим количеством I/O-операций при условии, что мы не блокируем основной поток тяжёлыми вычислениями.
