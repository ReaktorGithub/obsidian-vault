### 10 популярных вопросов по Webpack

1. **Что такое Webpack?**  
    Webpack - сборщик модулей. Он собирает JS, CSS, изображения и другие ресурсы в бандлы, которые браузер может загрузить и выполнить.
2. **Что такое entry и output?**  
    `entry` - точка входа в приложение. Webpack начинает анализ зависимостей с неё. `output` определяет, куда и под каким именем будут складываться собранные файлы.
3. **Что такое loader?**  
    Loader преобразует файлы перед сборкой. Например, `ts-loader` обрабатывает TypeScript, а `css-loader` позволяет импортировать CSS в JS.
4. **Чем loader отличается от plugin?**  
    Loader преобразует отдельные файлы, а plugin может вмешиваться в процесс сборки целиком. Например, `HtmlWebpackPlugin` генерирует HTML-файл.
5. **Что такое code splitting?**  
    Разделение одного большого бандла на несколько чанков. Например, через `import()` можно загрузить код страницы только тогда, когда пользователь её открыл.
6. **Что такое tree shaking?**  
    Удаление неиспользуемого кода из финального бандла. Особенно эффективно работает с ES-модулями благодаря статическому анализу `import` и `export`.
7. **Что такое webpack-dev-server?**  
    Локальный сервер для разработки. Он пересобирает приложение при изменениях и может обновлять страницу или модули без полной перезагрузки.
8. **Что такое HMR?**  
    Hot Module Replacement позволяет заменить изменённый модуль прямо во время работы приложения, не перезагружая всю страницу. Например, можно изменить CSS и сразу увидеть результат.
9. **Как уменьшить размер бандла Webpack?**  
    Использовать code splitting, tree shaking, минификацию, оптимизацию изображений и анализировать бандл через Bundle Analyzer. Также важно не тянуть тяжёлые библиотеки целиком, если нужна только часть функциональности.
10. **Что такое webpack mode?**  
    `development`, `production` и `none`. `production` включает оптимизации вроде минификации и tree shaking, а `development` настроен на удобную и быструю разработку.
