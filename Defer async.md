**Обычный:**

- HTML-парсер останавливается.
- Загружается JS.
- Выполняется JS.
- HTML-парсер продолжает работу.

**`defer`:**

- HTML продолжает парситься.
- JS загружается параллельно.
- Выполняется после полного разбора HTML.
- Скрипты с `defer` выполняются **по порядку**.

**`async`:**

- HTML продолжает парситься.
- JS загружается параллельно.
- Как только загрузился - **сразу выполняется**.
- Порядок нескольких `async` не гарантирован.
- Выполнение может прервать парсинг HTML.

**Запомнить:**

`script` → блокирует HTML при парсинге JS
`defer` → загружает параллельно, выполняет по порядку после парсинга HTML  
`async` → загружает параллельно, выполняет сразу после загрузки, не соблюдает порядок
