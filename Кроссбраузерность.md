
**Кроссбраузерность** - корректная работа сайта в разных браузерах и их версиях.

Основные движки:

- Chrome, Edge → **Blink**
    
- Firefox → **Gecko**
    
- Safari → **WebKit**
    

---

## Основные причины проблем

- Разная поддержка CSS/JS API
    
- Разная реализация стандартов
    
- Разные стандартные стили элементов
    
- Отличия в рендеринге
    
- Устаревшие версии браузеров
    
- Баги конкретного браузера
    

---

## Как решать проблемы

### 1. Проверять поддержку

**Can I Use** - проверка поддержки CSS/JS-функций браузерами.

Также смотреть спецификацию и MDN.

### 2. Fallback

Запасной вариант для неподдерживаемого свойства:

```css
.element {
  display: block;
  display: grid;
}
```

Старый браузер использует первое значение, современный - `grid`.

### 3. `@supports`

Проверка поддержки CSS:

```css
@supports (display: grid) {
  .element {
    display: grid;
  }
}
```

### 4. Autoprefixer

Автоматически добавляет необходимые вендорные префиксы:

```css
user-select: none;
```

может превратиться в:

```css
-webkit-user-select: none;
user-select: none;
```

Вручную префиксы обычно писать не нужно.

### 5. Browserslist

Определяет, какие браузеры нужно поддерживать.

```json
{
  "browserslist": [
    "last 2 versions",
    "> 1%",
    "not dead"
  ]
}
```

Autoprefixer ориентируется на эти настройки.

### 6. CSS Reset / Normalize

Убирают или нормализуют различия стандартных стилей браузеров.

Особенно актуально для:

- `button`
    
- `input`
    
- `select`
    
- `body`
    
- заголовков
    
- списков
    

### 7. Альтернативная реализация

Если технология не поддерживается, используем другой подход.

Например:

```text
CSS Grid
↓
fallback
↓
Flexbox
```

## Частые проблемные места CSS

- Flexbox
    
- Grid
    
- `position: sticky`
    
- `overflow`
    
- `100vh`
    
- `100dvh`
    
- формы и `input`
    
- `select`
    
- `appearance`
    
- `backdrop-filter`
    
- новые CSS-функции
    

---

## Вендорные префиксы

Исторически использовались:

```css
-webkit-
-moz-
-ms-
```

Сейчас обычно добавляются автоматически через **Autoprefixer**.

---

## Тестирование

Нужно тестировать **целевые браузеры**, а не абсолютно все.

Основные:

- Chrome
    
- Firefox
    
- Safari
    
- Edge
    

Для автоматизации можно использовать **Playwright**.

---

## Алгоритм поиска проблемы

```text
Проблема только в одном браузере
        ↓
Проверить поддержку
        ↓
Проверить Can I Use / MDN
        ↓
Проверить Browserslist
        ↓
Fallback / @supports
        ↓
Autoprefixer
        ↓
Альтернативная реализация
        ↓
Протестировать в целевом браузере
```

## Что сказать на собеседовании

> Кроссбраузерность - это корректная работа приложения в разных браузерах и версиях. Я определяю поддерживаемые браузеры через Browserslist, проверяю поддержку нужных API и CSS, использую Autoprefixer, fallback и `@supports`, а проблемы проверяю непосредственно в целевых браузерах. Для автоматического тестирования можно использовать Playwright.

---

## Главное

**Кроссбраузерность ≠ написать CSS один раз и проверить только Chrome.**

Нужно:

**определить целевые браузеры → проверить поддержку → предусмотреть fallback → автоматически добавить префиксы → протестировать.**
