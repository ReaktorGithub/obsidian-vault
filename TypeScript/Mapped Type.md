Mapped Type (отображаемый тип) - это механизм TypeScript, позволяющий создавать новые типы на основе существующего типа, перебирая его ключи и изменяя свойства.

### 1. Синтаксис

```
type NewType<T> = {
  [K in keyof T]: T[K];
};
```

- `keyof T` - получает объединение ключей типа `T`.
    
- `K in keyof T` - перебирает каждый ключ.
    
- `T[K]` - получает тип соответствующего свойства.
    

### 2. Пример изменения свойств

```
type User = {
  name: string;
  age: number;
};

type OptionalUser<T> = {
  [K in keyof T]?: T[K];
};

type User2 = OptionalUser<User>;

// Результат:
// {
//   name?: string;
//   age?: number;
// }
```

Знак `?` делает каждое свойство необязательным.

### 3. Модификаторы свойств

|Синтаксис|Действие|
|---|---|
|`?`|Делает свойства необязательными|
|`-?`|Убирает необязательность|
|`readonly`|Делает свойства доступными только для чтения|
|`-readonly`|Убирает `readonly`|

Пример:

```
type ReadonlyType<T> = {
  readonly [K in keyof T]: T[K];
};

type RequiredType<T> = {
  [K in keyof T]-?: T[K];
};
```

### 4. Встроенные Mapped Types

```
Partial<User>   // Все свойства необязательные
Required<User>  // Все свойства обязательные
Readonly<User>  // Все свойства только для чтения
```

### 5. Преобразование типов свойств

Можно изменять не только модификаторы, но и сами типы значений.

```
type User = {
  name: string;
  age: number;
};

type Stringify<T> = {
  [K in keyof T]: string;
};

type StringUser = Stringify<User>;

// {
//   name: string;
//   age: string;
// }
```

### Коротко для Obsidian

- Mapped Type - создание нового типа путём перебора ключей существующего типа.
    
- `[K in keyof T]` - перебирает ключи типа `T`.
    
- `T[K]` - извлекает тип свойства по ключу `K`.
    
- `?`, `-?`, `readonly`, `-readonly` позволяют изменять модификаторы свойств.
    
- Применяется для создания `Partial<T>`, `Required<T>`, `Readonly<T>` и пользовательских преобразований типов.
