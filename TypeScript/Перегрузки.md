Перегрузка функции - возможность описать несколько сигнатур одной функции для разных типов аргументов и возвращаемых значений.

Это позволяет одной функции работать с разными типами данных, сохраняя строгую типизацию.

## 1. Пример перегрузки

```
function getValue(value: string): string;
function getValue(value: number): number;

function getValue(value: string | number): string | number {
  if (typeof value === "string") {
    return value.toUpperCase();
  }

  return value * 2;
}

getValue("hello"); // string
getValue(10);      // number
getValue(true);    // Ошибка
```

Здесь:

- Сигнатуры перегрузки - первые две декларации, описывающие допустимые вызовы функции.
    
- Сигнатура реализации - последняя декларация с телом функции, реализующая логику.
    
- Сигнатура реализации не видна вызывающему коду как отдельная перегрузка.
    

TypeScript определяет тип результата на основании подходящей сигнатуры перегрузки.

## 2. Перегрузка с разным количеством аргументов

```
function createUser(name: string): object;
function createUser(name: string, age: number): object;

function createUser(name: string, age?: number): object {
  return age === undefined
    ? { name }
    : { name, age };
}

createUser("Oleg");       // OK
createUser("Oleg", 25);   // OK
createUser("Oleg", true); // Ошибка
```

## 3. Перегрузки методов класса

Перегружать можно не только обычные функции, но и методы классов.

```
class Formatter {
  format(value: string): string;
  format(value: number): string;

  format(value: string | number): string {
    return String(value);
  }
}

const formatter = new Formatter();

formatter.format("hello"); // string
formatter.format(123);     // string
```

## 4. Перегрузки vs Union Types

Иногда вместо перегрузок достаточно объединения типов.

Union Type

```
function print(value: string | number): void {
  console.log(value);
}
```

Функция принимает `string` или `number`, но тип результата и правила вызова одинаковы для обоих вариантов.

Перегрузки

```
function convert(value: string): number;
function convert(value: number): string;

function convert(value: string | number): string | number {
  return typeof value === "string"
    ? value.length
    : String(value);
}
```

Перегрузки позволяют связать конкретный тип аргумента с конкретным типом результата.

## 5. Важные правила

- Сначала объявляются сигнатуры перегрузок, затем одна реализация.
    
- Сигнатуры перегрузок не содержат тела функции.
    
- Реализация должна быть совместима со всеми сигнатурами перегрузки.
    
- При вызове TypeScript выбирает подходящую сигнатуру.
    
- Если ни одна сигнатура не подходит, возникает ошибка типов.
    
- Перегрузки существуют на этапе проверки типов и не создают отдельные реализации в JavaScript.
    

Коротко для Obsidian: перегрузка функции в TypeScript - это описание нескольких сигнатур одной функции для разных комбинаций аргументов и возвращаемых типов. Она нужна, когда тип результата зависит от типа или количества переданных аргументов.
