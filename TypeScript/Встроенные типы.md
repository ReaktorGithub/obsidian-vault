### PropertyKey

`PropertyKey` в TypeScript - это встроенный тип, который описывает все допустимые типы ключей свойств объекта.

```
type PropertyKey = string | number | symbol;
```

### Пример использования

```
function getProperty<T>(obj: T, key: PropertyKey) {
  return key;
}

getProperty({ name: "Oleg" }, "name"); // string
getProperty({ age: 25 }, 123);         // number
getProperty({}, Symbol("id"));         // symbol
```

### Где используется?

Чаще всего `PropertyKey` встречается в типизации ключей объектов, например в `Record`:

```
type User = Record<PropertyKey, string>;
```

Однако `PropertyKey` **не гарантирует, что конкретный ключ существует в объекте**. Он лишь описывает допустимые типы ключей.

Для ограничения ключей конкретными свойствами объекта используют `keyof`:

```
type User = {
  name: string;
  age: number;
};

type UserKey = keyof User; // "name" | "age"
```

**Коротко для Obsidian:**

- `PropertyKey` - тип, объединяющий `string | number | symbol`.
- `keyof T` - тип, представляющий объединение ключей объекта `T`.
- `PropertyKey` описывает допустимые типы ключей, а `keyof` позволяет получить ключи конкретного типа объекта.


В TypeScript есть встроенные типы, которые объявлены в стандартных декларациях языка (`lib.*.d.ts`). Помимо `PropertyKey`, к ним относятся типы для работы с объектами, функциями, итераторами, генераторами и асинхронными операциями.

Важно различать встроенные типы TypeScript и примитивные типы (`string`, `number`, `boolean`), а также Utility Types (`Partial`, `Pick`, `ReturnType` и другие).

Ниже - основные встроенные служебные типы, которые полезно знать разработчику.

## 1. Типы объектов и функций

|Тип|Что означает|
|---|---|
|`object`|Любое непримитивное значение: объект, массив, функция и т. д.|
|`Function`|Общий тип функции; обычно лучше использовать конкретную сигнатуру функции|
|`CallableFunction`|Тип для вызываемых функций с дополнительной типизацией операций над ними|
|`NewableFunction`|Тип для функций, которые можно вызывать через `new`|

Примеры:

```
let obj: object;

obj = {};
obj = [];
obj = () => {};
// obj = 123; // Ошибка
```

```
const greet: (name: string) => string = (name) => `Hello, ${name}`;
```

В реальном коде лучше описывать сигнатуру функции, а не использовать общий тип `Function`.

## 2. Типы для итераторов

|Тип|Что означает|
|---|---|
|`Iterable<T>`|Объект, который можно перебирать и который выдаёт значения типа `T`|
|`Iterator<T>`|Объект, выдающий значения через метод `next()`|
|`IteratorResult<T, TReturn>`|Результат вызова `next()` итератора|
|`IteratorYieldResult<T>`|Результат итератора, который выдал очередное значение|
|`IteratorReturnResult<TReturn>`|Результат завершения итератора|
|`IterableIterator<T>`|Итератор, который также является итерируемым объектом|
|`IteratorObject<T, TReturn, TNext>`|Тип итератора с поддержкой итерационного протокола в современных версиях TypeScript|

Пример:

```
const iterator = [10, 20][Symbol.iterator]();

const result: IteratorResult<number> = iterator.next();

console.log(result);
// { value: 10, done: false }
```

## 3. Типы для асинхронных итераторов

|Тип|Что означает|
|---|---|
|`AsyncIterable<T>`|Объект, который можно перебирать асинхронно|
|`AsyncIterator<T>`|Итератор, у которого `next()` возвращает Promise|
|`AsyncIterableIterator<T>`|Асинхронный итератор, который также является итерируемым|
|`AsyncIteratorObject<T, TReturn, TNext>`|Тип асинхронного итератора в современных декларациях TypeScript|

Пример:

```
async function* generateNumbers() {
  yield 1;
  yield 2;
}

async function main() {
  for await (const value of generateNumbers()) {
    console.log(value);
  }
}
```

`for await...of` позволяет последовательно получать значения из асинхронного итерируемого объекта.

## 4. Типы для генераторов

|Тип|Что означает|
|---|---|
|`Generator<T, TReturn, TNext>`|Тип синхронного генератора|
|`GeneratorFunction`|Тип функции-генератора|
|`AsyncGenerator<T, TReturn, TNext>`|Тип асинхронного генератора|
|`AsyncGeneratorFunction`|Тип функции асинхронного генератора|

Пример:

```
function* numbers(): Generator<number, void, unknown> {
  yield 1;
  yield 2;
}
```

Параметры `Generator<T, TReturn, TNext>` означают:

- `T` - тип значений, выдаваемых через `yield`.
    
- `TReturn` - тип итогового значения при завершении.
    
- `TNext` - тип значений, передаваемых внутрь генератора через `next(value)`.
    

## 5. Типы для массивоподобных структур

|Тип|Что означает|
|---|---|
|`ArrayLike<T>`|Объект с числовым свойством `length` и индексируемыми элементами типа `T`|
|`ConcatArray<T>`|Тип массива, используемый в декларациях операции `concat`|

Пример `ArrayLike`:

```
function printItems(items: ArrayLike<string>) {
  for (let i = 0; i < items.length; i++) {
    console.log(items[i]);
  }
}

printItems({ 0: "A", 1: "B", length: 2 });
```

`ArrayLike<T>` не требует наличия методов массива и не гарантирует, что объект итерируемый.

## 6. Типы для Promise

|Тип|Что означает|
|---|---|
|`Promise<T>`|Асинхронный результат типа `T`|
|`PromiseLike<T>`|Объект, совместимый с Promise по наличию метода `then`|

Пример:

```
const result: Promise<number> = Promise.resolve(42);
```

`PromiseLike<T>` полезен при описании объектов, которые могут быть приняты через `await` или обработаны как Promise, но не обязательно являются экземплярами `Promise`.

## 7. Типы для `this` и шаблонных строк

|Тип|Что означает|
|---|---|
|`ThisParameterType<T>`|Извлекает тип параметра `this` функции|
|`OmitThisParameter<T>`|Удаляет явный параметр `this` из типа функции|
|`ThisType<T>`|Задаёт контекстный тип `this` в подходящих объектных литералах|
|`TemplateStringsArray`|Тип массива строковых частей шаблонного литерала, передаваемого тегированной шаблонной функции|

Последние три типа для `this` являются Utility Types и уже относятся к категории преобразования типов, а не к отдельным типам объектов во время выполнения.

Пример `TemplateStringsArray`:

```
function tag(strings: TemplateStringsArray, value: number) {
  console.log(strings[0], value);
}

tag`Value: ${42}`;
```

## 8. Типы для бинарных данных

В стандартных декларациях JavaScript также присутствуют типы для работы с бинарными данными:

|Тип|Что означает|
|---|---|
|`ArrayBufferLike`|Обобщённый тип буфера бинарных данных|
|`ArrayBuffer`|Область памяти для бинарных данных|
|`SharedArrayBuffer`|Буфер памяти, доступный нескольким агентам|
|`DataView`|Позволяет читать и записывать разные числовые типы в буфере|
|`ArrayBufferView`|Представление буфера через `DataView` или типизированный массив|

Пример:

```
const buffer = new ArrayBuffer(8);
const view = new DataView(buffer);

view.setInt32(0, 42);

console.log(view.getInt32(0)); // 42
```

Доступность конкретных типов зависит от используемой версии TypeScript, целевого окружения и подключённых библиотек.

## 9. Встроенные типы-обёртки

В стандартных декларациях также есть `Object`, `String`, `Number`, `Boolean` и `Symbol`.

Они связаны с объектными представлениями значений, но в обычной типизации лучше использовать примитивные типы:

```
let name: string = "Oleg";
let age: number = 25;
let active: boolean = true;
```

Вместо:

```
let name: String = "Oleg"; // Не рекомендуется
let age: Number = 25;      // Не рекомендуется
```

`Object` также не стоит путать с `object`: первый относится к стандартному интерфейсу JavaScript, второй - к типу TypeScript, исключающему примитивы.

## 10. Что важно запомнить

На практике наиболее полезны следующие типы:

- `object` - непримитивные значения.
    
- `Iterable<T>` и `Iterator<T>` - протокол итерации.
    
- `AsyncIterable<T>` и `AsyncIterator<T>` - асинхронная итерация.
    
- `Generator<T, TReturn, TNext>` - генераторы.
    
- `ArrayLike<T>` - массивоподобные объекты.
    
- `Promise<T>` и `PromiseLike<T>` - асинхронные операции.
    
- `ArrayBuffer`, `DataView`, `ArrayBufferLike` - бинарные данные.
    
- `TemplateStringsArray` - тегированные шаблонные литералы.
    

Это основные категории встроенных служебных типов, а не абсолютно полный перечень всех деклараций стандартной библиотеки: их набор зависит от версии TypeScript и подключённых `lib`.
