**Шаблонные литеральные типы** позволяют создавать новые строковые типы на основе других типов, используя синтаксис шаблонных строк с обратными кавычками.
### 1. Базовый пример

```
type Direction = "top" | "bottom";
type Position = `position-${Direction}`;

// Результат:
// "position-top" | "position-bottom"

const a: Position = "position-top"; // OK
const b: Position = "position-bottom"; // OK
const c: Position = "position-left"; // Ошибка
```

TypeScript автоматически формирует все возможные строковые варианты.

### 2. Объединение нескольких типов

```
type Color = "red" | "green";
type Size = "small" | "large";

type Style = `${Size}-${Color}`;

// Результат:
// "small-red"
// "small-green"
// "large-red"
// "large-green"
```

Если в шаблоне несколько типов-объединений, TypeScript создаёт все возможные комбинации.

### 3. Использование `string`, чисел и литералов

```
type UserId = `user-${number}`;

const a: UserId = "user-123"; // OK
const b: UserId = "user-42";  // OK
const c: UserId = "admin-1";  // Ошибка
```

`number` позволяет использовать числовые значения внутри строки, но не проверяет формат числа как регулярное выражение.

### 4. Преобразование строковых ключей

Шаблонные литеральные типы удобно использовать для создания обработчиков событий и других типов на основе строк.

```
type EventName = "click" | "focus" | "blur";

type HandlerName = `on${Capitalize<EventName>}`;

// Результат:
// "onClick" | "onFocus" | "onBlur"
```

Здесь используется встроенный Utility Type `Capitalize`, который делает первую букву строки заглавной.

### 5. Связь с `keyof`

Можно создавать строковые типы на основе ключей объектов.

```
type User = {
  name: string;
  age: number;
};

type UserEvent = `${keyof User}Changed`;

// Результат:
// "nameChanged" | "ageChanged"
```

Пример использования:

```
type User = {
  name: string;
  age: number;
};

type UserEvent = `${keyof User}Changed`;

function on(event: UserEvent) {
  console.log(event);
}

on("nameChanged"); // OK
on("ageChanged");  // OK
on("emailChanged"); // Ошибка
```

### 6. Использование с `infer`

Шаблонные литеральные типы позволяют извлекать части строк с помощью `infer`.

```
type ExtractId<T> = T extends `user-${infer Id}`
  ? Id
  : never;

type A = ExtractId<"user-123">; // "123"
type B = ExtractId<"admin-456">; // never
```

`infer Id` позволяет вывести тип части строки, соответствующей шаблону.

### 7. Встроенные типы для преобразования строк

TypeScript предоставляет несколько Utility Types:

|Тип|Назначение|Пример|
|---|---|---|
|`Uppercase<S>`|Преобразует строку в верхний регистр|`Uppercase<"hello">` → `"HELLO"`|
|`Lowercase<S>`|Преобразует строку в нижний регистр|`Lowercase<"HELLO">` → `"hello"`|
|`Capitalize<S>`|Делает первую букву заглавной|`Capitalize<"hello">` → `"Hello"`|
|`Uncapitalize<S>`|Делает первую букву строчной|`Uncapitalize<"Hello">` → `"hello"`|

### Кратко для Obsidian

- **Template Literal Types** — шаблонные литеральные типы, позволяющие создавать строковые типы с помощью шаблонов.
- Синтаксис: `` type T = `prefix-${SomeType}` ``.
- Поддерживают объединения (`|`), `keyof`, `infer` и встроенные Utility Types.
- Если используются объединения, TypeScript формирует все возможные комбинации строк.
- Применяются для типизации событий, API-маршрутов, CSS-классов, идентификаторов и строковых соглашений.
- Работают на уровне типов и не создают строки во время выполнения.
