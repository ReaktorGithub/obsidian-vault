
### `git merge`

- Объединяет две ветки.
- Сохраняет историю изменений.
- Может создать **merge commit**.

```
git checkout main
git merge feature
```

**Когда использовать:** для безопасного объединения веток без переписывания истории.

---

### `git rebase`

- Переносит коммиты одной ветки поверх другой.
- Делает историю линейной.
- Переписывает историю коммитов.

```
git checkout feature
git rebase main
```

**Когда использовать:** перед слиянием, чтобы обновить ветку и сделать историю чище.

> Не рекомендуется делать `rebase` для уже опубликованных (shared) коммитов.

---

### `git cherry-pick`

- Копирует **один или несколько конкретных коммитов** из одной ветки в другую.
- Остальная история не переносится.

```
git cherry-pick <commit-hash>
```

**Когда использовать:** если нужно перенести отдельное исправление или фичу без слияния всей ветки.
