- **AI-агенты** - Claude Code, Cursor, Codex и т.д. Ты не просто спрашиваешь у ChatGPT код, а ставишь агенту задачу, даёшь доступ к проекту, он сам анализирует файлы, пишет код, запускает команды и исправляет ошибки.
- **Управление контекстом** - понимать, какую информацию дать агенту. Например, архитектуру проекта, требования, ограничения, конкретные файлы. Большую задачу разбивать на небольшие этапы, чтобы агент не потерял контекст.
- **Сессии** - понимать, когда продолжать текущий диалог с агентом, а когда начать новый. Например, закончил фичу - новую независимую задачу лучше начать с чистого контекста.
- **MCP** - стандарт, который позволяет AI-агенту подключаться к внешним инструментам и данным. Например, GitHub, Jira, база данных, файловая система или внутренняя документация.
- **Ревью AI-кода** - агент написал код, но ты не принимаешь его вслепую. Проверяешь архитектуру, типизацию, безопасность, производительность, тесты и соответствие проекту. После этого доводишь код до production-ready состояния.

RAG (Retrieval-Augmented Generation) — подход, при котором LLM перед ответом получает релевантную информацию из внешнего источника.

Упрощённо:

1. Пользователь задаёт вопрос.
2. Система ищет подходящие данные в базе знаний, документации, базе данных и т.д.
3. Найденная информация передаётся вместе с вопросом в LLM.
4. Модель формирует ответ, опираясь на эти данные.

Например, у компании есть 10 000 документов. Вместо того чтобы обучать модель на них, можно сделать RAG: пользователь спрашивает про внутреннюю инструкцию, система находит нужные фрагменты документов и передаёт их модели.

Главный плюс — модель может работать с актуальными и приватными данными, которых не было в её обучении. При этом RAG не является дообучением модели.

CLI

**CLI для нейросетей** это интерфейс командной строки, через который с ИИ работают из терминала вместо графического интерфейса.

Например:

```
claude
codex
gemini
```

Через CLI можно отправлять запросы модели, анализировать код, работать с файлами, запускать команды и автоматизировать задачи.
