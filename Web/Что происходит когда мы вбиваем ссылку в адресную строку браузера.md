1. **DNS Lookup** — разрешение домена в IP
2. **TCP Handshake** — установка соединения
3. **TLS Handshake** — для HTTPS
4. **HTTP Request** — браузер запрашивает HTML
5. **HTML Parsing** — парсинг HTML, построение DOM
6. **CSS Parsing** — парсинг CSS, построение CSSOM
7. **JavaScript Execution** — выполнение скриптов (блокирует парсинг)
8. **DOM + CSSOM → Render Tree** — объединение в дерево рендеринга
9. **Layout (Reflow)** — вычисление геометрии элементов
10. **Paint** — отрисовка пикселей
11. **Composite** — объединение слоёв в итоговое изображение

**Критические моменты:**

- **FCP (First Contentful Paint)** — первый контент на экране (шаг 10)
- **LCP (Largest Contentful Paint)** — largest элемент отрисован
- **TTI (Time to Interactive)** — страница полностью интерактивна
