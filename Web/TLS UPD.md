**TCP (Transmission Control Protocol)** - транспортный протокол, который обеспечивает **надёжную передачу данных между двумя устройствами**.

**UDP (User Datagram Protocol)** - транспортный протокол, который отправляет данные без установки соединения и без гарантии доставки. Он быстрее TCP, но пакеты могут потеряться или прийти не по порядку.

**TLS (Transport Layer Security)** - протокол шифрования данных при передаче по сети. Он обеспечивает конфиденциальность, целостность и аутентификацию сервера. Например, `HTTPS` работает поверх `TLS`.
