
**Array**

- доступ по индексу - O(1)
- поиск - O(n)
- добавление в конец - O(1) в среднем
- добавление в начало - O(n)

**Object / Hash Table / Map**

- поиск - O(1) в среднем
- добавление - O(1) в среднем
- удаление - O(1) в среднем

**Set**

- хранение уникальных значений
- `has`, `add`, `delete` - O(1) в среднем

**Stack**

- LIFO
- последний добавленный элемент выходит первым
- `push`, `pop` - O(1)

**Queue**

- FIFO
- первый добавленный элемент выходит первым
- добавление и удаление - O(1)

**Linked List**

- поиск - O(n)
- вставка или удаление по известному узлу - O(1)

**Tree**

- иерархическая структура
- поиск зависит от типа дерева

**Graph**

- вершины + рёбра
- используется для сетей, маршрутов, зависимостей
