# Поиск

### Линейный поиск

Идём по всем элементам.

**O(n)**

### Бинарный поиск

Работает только на **отсортированном** массиве.

На каждом шаге отбрасывает половину элементов.

**O(log n)**

[1 3 5 7 9 11 13]

        ↑

     середина

# 6. Основные методы решения задач

### Brute Force

Полный перебор всех вариантов.

Просто реализовать, но часто высокая сложность.

**Пример:** проверить все пары элементов - O(n²).

---

### Divide and Conquer

**Разделяй и властвуй.**

1. Разделить задачу.
2. Решить подзадачи.
3. Объединить результаты.

Примеры:

- Merge Sort
- Quick Sort
- Binary Search

---

### Greedy

**Жадный алгоритм.**

На каждом шаге выбирает локально лучшее решение.

Пример:

- выбор минимального количества монет в некоторых вариантах задачи о размене
- выбор задач с максимальной выгодой

Не всегда приводит к глобально оптимальному решению.

---

### Dynamic Programming

**Динамическое программирование.**

Разбиваем задачу на подзадачи и сохраняем уже вычисленные результаты.

Основные признаки:

- повторяющиеся подзадачи
- оптимальная подструктура

Примеры:

- числа Фибоначчи
- рюкзак
- наибольшая общая подпоследовательность

Два подхода:

**Memoization** - рекурсия + кеш.

**Tabulation** - решение снизу вверх через таблицу.

---

### Backtracking

Перебираем варианты и откатываемся, если текущий вариант не подходит.

Пример:

выбрать → проверить → продолжить

                 ↓

              не подходит

                 ↓

               откат

Используется для:

- Sudoku
- N-Queens
- комбинаций
- перестановок

Часто имеет экспоненциальную сложность.

---

# 7. Два указателя

Используем два индекса вместо вложенных циклов.

left →          ← right

[1 2 3 4 5 6 7]

Часто позволяет получить **O(n)** вместо O(n²).

Применяется для:

- поиска пары
- работы с отсортированным массивом
- разворота массива
- удаления дубликатов

---

# 8. Sliding Window

**Скользящее окно** используется для последовательных участков массива или строки.

[1 2 3] 4 5 6

 ↑────↑

  окно

Вместо пересчёта каждого окна поддерживаем его состояние.

Часто позволяет получить **O(n)**.

Примеры:

- максимальная сумма подмассива длины `k`
- самая длинная подстрока без повторов

---

# 9. Prefix Sum

**Префиксные суммы** позволяют быстро получать сумму диапазона.

arr:    2  4  1  3

prefix: 2  6  7 10

После предварительного вычисления:

- построение - O(n)
- сумма диапазона - O(1)

---

# 10. Рекурсия

Функция вызывает саму себя.

Обязательно должно быть:

1. **Базовое условие**
2. **Рекурсивный переход**

function factorial(n) {

  if (n <= 1) return 1

  return n * factorial(n - 1)

}

Минус - расход памяти на **call stack**.

---

# 11. Графы

Основные способы обхода:

### BFS

**Обход в ширину.**

Использует очередь.

Идёт по уровням.

**O(V + E)**

Хорош для поиска кратчайшего пути в невзвешенном графе.

### DFS

**Обход в глубину.**

Использует рекурсию или стек.

**O(V + E)**

Используется для:

- поиска компонентов
- проверки циклов
- обхода графа
- задач на зависимости

---

# 12. Кратчайшие пути

**Dijkstra**

Ищет кратчайшие пути от одной вершины.

Работает с **неотрицательными весами**.

**Bellman-Ford**

Может работать с отрицательными рёбрами.

**Floyd-Warshall**

Ищет кратчайшие пути между **всеми парами вершин**.
