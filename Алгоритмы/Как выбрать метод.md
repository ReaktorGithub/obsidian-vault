Удобная последовательность:

**1. Понять ограничения**

Сколько элементов? `n = 100`, `10 000` или `1 000 000`?

**2. Сначала придумать простое решение**

Brute Force.

**3. Оценить Big O**

Если получилось O(n²), подумать, можно ли улучшить.

**4. Найти структуру задачи**

- отсортированный массив → Binary Search
- последовательный диапазон → Sliding Window
- поиск пары → Two Pointers или Hash Map
- повторяющиеся подзадачи → Dynamic Programming
- варианты и комбинации → Backtracking
- граф → BFS или DFS
- локально лучший выбор → Greedy

**5. Проверить крайние случаи**

- пустой массив
- один элемент
- дубликаты
- отрицательные числа
- очень большой `n`

### Самое важное для собеседования

Стоит хорошо знать:

**Big O → Array → Map → Set → Stack → Queue → Binary Search → Two Pointers → Sliding Window → Recursion → BFS → DFS → Sorting → Greedy → Dynamic Programming → Backtracking.**
