### Bubble Sort

Сравнивает соседние элементы и меняет их местами.

- лучший случай - O(n)
- средний - O(n²)
- худший - O(n²)
- память - O(1)

Для реальных задач практически не используется.

### Selection Sort

На каждом шаге ищет минимальный элемент и ставит его на нужную позицию.

- O(n²)
- память - O(1)

### Insertion Sort

Берёт очередной элемент и вставляет его в правильное место уже отсортированной части.

- лучший - O(n)
- средний - O(n²)
- худший - O(n²)
- хорош для маленьких или почти отсортированных массивов.

### Merge Sort

Делит массив пополам, сортирует части и объединяет.

- O(n log n)
- память - O(n)
- стабильная сортировка

### Quick Sort

Выбирает **pivot**, делит элементы на меньшие и большие и рекурсивно сортирует части.

- средний - O(n log n)
- худший - O(n²)
- обычно память - O(log n) для стека рекурсии

### Heap Sort

Использует структуру **куча**.

- O(n log n)
- память - O(1)
- нестабильная

**Главное для собеседования:**

> Merge Sort - гарантированно O(n log n), но требует дополнительную память.  
> Quick Sort - в среднем O(n log n), но в худшем случае O(n²).
