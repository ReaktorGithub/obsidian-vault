**Стек (Stack)** - принцип **LIFO**: последний добавленный элемент выходит первым.  
Как стопка тарелок: положили `A → B → C`, достанем `C → B → A`.  
Основные операции: `push` - добавить, `pop` - достать, `peek` - посмотреть верхний.

**Очередь (Queue)** - принцип **FIFO**: первый добавленный элемент выходит первым.  
Как очередь людей: `A → B → C`, первым уйдёт `A`.  
Основные операции: `enqueue` - добавить в конец, `dequeue` - достать из начала.

**Дек (Deque)** - очередь, в которой можно добавлять и удалять элементы **с обоих концов**.  
Например: `A B C` → можно добавить `D` слева или `E` справа.

**Массив (Array)** - элементы лежат последовательно и доступны по индексу.  
`arr[0]`, `arr[1]`, `arr[2]`. Получение элемента по индексу обычно `O(1)`.

**Связный список (Linked List)** - каждый элемент хранит значение и ссылку на следующий элемент.  
`A → B → C → null`. Быстрая вставка и удаление при наличии нужного узла, но поиск элемента обычно `O(n)`.

**Множество (Set)** - коллекция **уникальных** элементов.  
Например: `{1, 2, 3}`. Дубликаты автоматически не хранятся.

**Словарь / Map** - структура `ключ → значение`.  
Например: `userId → user`. Обычно поиск по ключу `O(1)`.

**Хеш-таблица (Hash Table)** - структура, лежащая в основе многих `Map` и `Set`. Использует хеш-функцию, чтобы быстро находить данные по ключу.

**Дерево (Tree)** - иерархическая структура из узлов.  
Например:

```
        A
       / \
      B   C
     / \
    D   E
```

**Бинарное дерево** - у каждого узла максимум два ребёнка.

**Бинарное дерево поиска (BST)** - слева значения меньше узла, справа больше. В сбалансированном случае поиск может быть `O(log n)`.

**Куча (Heap)** - дерево, которое позволяет быстро получать минимальный или максимальный элемент. Используется, например, в **Priority Queue**.

**Граф (Graph)** - вершины и связи между ними.  
Например, города и дороги между ними. Может быть ориентированным или неориентированным.

### Самая полезная шпаргалка

```
Stack       → LIFO → последний вошёл, первый вышел
Queue       → FIFO → первый вошёл, первый вышел
Deque       → оба конца
Array       → индекс → быстрый доступ
Linked List → ссылки → последовательность узлов
Set         → уникальные значения
Map         → ключ → значение
Tree        → иерархия
Heap        → min/max элемент
Graph       → вершины + связи
```

Для собеседования по алгоритмам особенно важно хорошо понимать **Stack, Queue, Array, Linked List, Hash Table, Tree, Heap и Graph**.
