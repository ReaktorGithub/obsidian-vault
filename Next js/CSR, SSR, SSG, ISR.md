**CSR — Client Side Rendering**

HTML приходит почти пустым, UI рендерится в браузере через JS.

### Плюсы

- богатая интерактивность;
- быстрые переходы внутри SPA.

### Минусы

- хуже SEO;
- медленный First Paint;
- blank screen до загрузки JS.

Пример: React SPA на Vite.

---

## SSR — Server Side Rendering

HTML генерируется на сервере для каждого запроса.

### Плюсы

- хороший SEO;
- быстрый First Paint;
- контент виден без JS.

### Минусы

- выше нагрузка на сервер;
- hydration может быть дорогой.

Пример: Next.js SSR.

---

## SSG — Static Site Generation

HTML генерируется заранее во время build.

### Плюсы

- очень быстрый;
- отличный SEO;
- можно отдавать через CDN.

### Минусы

- данные не realtime;
- rebuild при изменениях.

Подходит для:

- блогов;
- документации;
- landing pages.

---

## ISR — Incremental Static Regeneration

Гибрид SSG + SSR.

Страницы статические, но могут пересобираться после deploy.

Пример:

- revalidate: 60 секунд.

---

## Streaming SSR

Сервер отправляет HTML частями.

Пользователь видит контент раньше полной загрузки.

Используется в:

- React 18;
- Next.js App Router.

---

## SPA

Single Page Application:

- одна HTML-страница;
- роутинг и рендеринг на клиенте.

Обычно CSR.

---

## MPA

Multi Page Application:

- каждая страница загружается отдельно с сервера.

Классический серверный рендеринг.

---

## Краткое сравнение

| Подход            | Где рендерится  | SEO      | Скорость               | Где лучше использовать                                                                     |
| ----------------- | --------------- | -------- | ---------------------- | ------------------------------------------------------------------------------------------ |
| **CSR**           | Браузер         | Плохой   | Медленный первый экран | Личные кабинеты, админки, SPA, внутренние сервисы                                          |
| **SSR**           | Сервер          | Хороший  | Быстрый First Paint    | E-commerce, динамические каталоги, персонализированные страницы                            |
| **SSG**           | Build time      | Отличный | Очень быстрый          | Landing page, документация, блог, маркетинговые страницы                                   |
| **ISR**           | Build + runtime | Отличный | Быстрый                | Блоги, новости, каталоги, e-commerce с часто обновляемым контентом                         |
| **Streaming SSR** | Сервер потоками | Хороший  | Ещё быстрее UX         | Сложные динамические страницы, e-commerce, дашборды, страницы с большим количеством данных |
