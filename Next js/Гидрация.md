## Hydration

После SSR React «оживляет» HTML:

1. читает существующий DOM
2. строит virtual DOM
3. сравнивает их
4. подвешивает:
    - event listeners
    - state
    - hooks

После этого UI становится интерактивным.

# Hydration mismatch

Частая проблема:

```
Hydration failedText content does not match
```

---

## Почему возникает

Серверный HTML отличается от клиентского.

Например:

```
<div>{Math.random()}</div>
```

На сервере:

```
0.123
```

На клиенте:

```
0.987
```

React видит несовпадение.

---

# Типичные причины

- `Math.random()`
- `Date.now()`
- работа с `window`
- browser-only API
- locale differences
- async race conditions
