Вопрос про хранение данных, как в Redux:

React Query хранит данные в глобальном query cache, поэтому ими могут пользоваться разные компоненты. Но это в первую очередь хранилище серверного состояния: кеширование, синхронизация с API, refetch и управление loading и error. Redux больше подходит для клиентского состояния приложения.
