плюсы

- **Меньше ререндеров** — поля хранятся через `ref` и подписки, поэтому изменение одного поля обычно не вызывает перерендер всей формы.
- **Производительность** — хорошо подходит для больших и сложных форм.
- **Простая валидация** — есть встроенные правила `required`, `min`, `max`, `pattern` и т.д.
- **Интеграция с Yup, Zod, Joi** — удобно выносить схему валидации отдельно.
- **Удобная работа со сложными формами** — `useFieldArray` для динамических массивов полей, `Controller` для сторонних компонентов.
- **Мало кода** — базовая форма получается достаточно компактной.
- **Хорошая работа с uncontrolled components** — не нужно держать значение каждого `input` в React state.
- **Есть удобные механизмы для ошибок, dirty state, touched state, submit state** — `errors`, `isDirty`, `isValid`, `isSubmitting` и т.д.

### Минусы

- **Порог входа выше, чем у обычного `useState`**. Нужно понимать `register`, `control`, `Controller`, `watch`, `setValue`, `reset` и подписки.
- **Uncontrolled-подход может быть непривычным** для разработчика, привыкшего полностью контролировать поля через `value` и `onChange`.
- **`Controller` добавляет сложности** при работе с UI-библиотеками вроде MUI, Ant Design или кастомными компонентами.
- **Сложнее отлаживать**, когда форма большая и используются `watch`, `useWatch`, `setValue`, `reset` и зависимости между полями.
- **Есть привязка к библиотеке** — логика формы становится зависимой от API React Hook Form.
- Для **очень простой формы** библиотека может быть избыточной. Иногда несколько `useState` проще и понятнее.

### На собеседовании я бы сформулировал так

> React Hook Form удобен прежде всего для сложных форм. Его основное преимущество в производительности: он использует преимущественно uncontrolled-подход и подписки, поэтому изменения отдельных полей не приводят к ререндеру всей формы. Плюс есть удобная работа с валидацией, ошибками и динамическими полями. Из минусов — более сложный API и необходимость отдельно разбираться с `Controller` при интеграции с контролируемыми компонентами.
