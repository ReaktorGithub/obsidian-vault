### Controlled

Состояние элемента хранится в **React state**, а значение передаётся через `value` или `checked`.

```
const [value, setValue] = useState('');

<input
  value={value}
  onChange={e => setValue(e.target.value)}
/>
```

React полностью контролирует значение поля.

**Выбираю controlled**, когда:

- нужно валидировать данные во время ввода;
- интерфейс зависит от значения поля;
- нужно динамически менять или сбрасывать значение;
- нужна сложная логика формы.

### Uncontrolled

Состояние хранится **в самом DOM**, а React получает значение через `ref`.

```
const inputRef = useRef();

<input ref={inputRef} />

console.log(inputRef.current.value);
```

**Выбираю uncontrolled**, когда:

- не нужно реагировать на каждое изменение значения;
- форма простая;
- хочется уменьшить количество ререндеров;
- работаю с большими формами, где значения удобно получать непосредственно перед отправкой.

### На собеседовании

> Controlled-компонентом React управляет через state: значение хранится в состоянии и обновляется через `onChange`. В uncontrolled значение хранится в DOM, а React обращается к нему через `ref`. Controlled выбираю для сложной логики и валидации, uncontrolled — когда достаточно получить значение при submit и не нужен контроль каждого изменения.
