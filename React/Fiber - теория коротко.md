React Fiber - это новый движок согласования, изменения основного алгоритма в React 16. Основной задачей React Fiber является повышение производительности в таких областях как:

- анимация,
- создание макета страницы,
- возможность приостанавливать, прерывать или повторно запускать выполнение операций
- и предоставление приоритета определенным типом обновлений.

Его основная особенность - это т.н. incremental rendering или инкрементальный рендеринг - это возможность разделения процесса рендеринга на части и их объединение через различные фреймы.

React Fiber - это новый алгоритм согласования (reconciliation) и рендеринга, введенный в React версии 16.

Есть связанный список нодов. Каждая нода имеет ссылки на: родителя, первого потомка, следующего соседа того же уровня, alternate (ссылка на две версии одного и того же дерева: current tree, work-in-progress tree)

Основная цель React Fiber заключается в улучшении производительности и отзывчивости пользовательского интерфейса. Он предназначен для обеспечения плавной анимации, быстрой реакции на пользовательские действия и разделения работы на небольшие инкрементные задачи, чтобы избежать блокировки основного потока выполнения JavaScript.

Основные характеристики React Fiber включают:

1. **Архитектурные изменения:** React Fiber переработывает внутреннюю структуру и архитектуру React, разбивая процесс согласования на маленькие задачи, которые могут быть приостановлены, возобновлены и прерваны при необходимости.
2. **Приоритеты и отложенное согласование:** Fiber вводит понятие приоритетов задач, что позволяет React определить, какие задачи имеют более высокий приоритет и должны быть выполнены сначала. Это позволяет сделать отзывчивый интерфейс, даже если есть много работы для выполнения. Также React Fiber поддерживает отложенное согласование, что означает, что обновления компонентов могут быть приостановлены или отменены, если они больше не нужны.
3. **Возобновление (Suspense) и Ленивая загрузка (Lazy loading):** Fiber предоставляет возможность использовать механизмы возобновления (Suspense) и ленивой загрузки (Lazy loading). Возобновление позволяет компонентам отображать запасное содержимое или ожидать загрузки данных, прежде чем отображать основное содержимое. Ленивая загрузка позволяет откладывать загрузку компонентов до тех пор, пока они не понадобятся, что помогает ускорить начальную загрузку приложения.

React Fiber значительно улучшает производительность React-приложений, особенно в ситуациях, когда имеется большое количество компонентов или сложная иерархия компонентов. Однако, для большинства разработчиков, работа с React Fiber скрыта за интерфейсом React API, и они могут продолжать создавать компоненты и разрабатывать приложения, как и раньше, без явной работы с Fiber.
