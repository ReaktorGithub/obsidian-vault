
`useId` — хук React 18 для генерации **уникального стабильного ID**, особенно полезного при **SSR и гидрации**.

```
const id = useId();

return (
  <>
    <label htmlFor={id}>Email</label>
    <input id={id} />
  </>
);
```

Главное преимущество — ID будет согласован между **серверным и клиентским рендерингом**, поэтому не возникает проблем при hydration.

**На собеседовании:**

> `useId` генерирует уникальный стабильный ID для связывания элементов, например `label` и `input`. Особенно полезен в SSR, потому что ID совпадает между сервером и клиентом.

Помимо SSR, `useId` используют, когда компоненту нужен **стабильный уникальный ID**:

- **Связка `label` и `input`** через `htmlFor` / `id`
- **Accessibility** — `aria-describedby`, `aria-labelledby`
- **Связь `input` и `error`/`hint`**
- **Сложные компоненты** — например, `Select`, `Accordion`, `Modal`
- **Несколько экземпляров одного компонента** на странице — чтобы ID не пересекались

Пример с accessibility:

```
const id = useId();

return (
  <>
    <input aria-describedby={`${id}-hint`} />
    <span id={`${id}-hint`}>Введите email</span>
  </>
);
```

Важно: `useId` **не стоит использовать для `key` в списках** и для генерации ID, которые должны меняться при каждом рендере.
