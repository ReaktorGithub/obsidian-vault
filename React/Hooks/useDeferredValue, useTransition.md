### `useTransition`

Позволяет пометить обновление состояния как **не срочное**.

```
const [isPending, startTransition] = useTransition();

const handleChange = (value) => {
  setInput(value); // срочно

  startTransition(() => {
    setSearch(value); // можно выполнить позже
  });
};
```

Идея:

```
Ввод пользователя → высокий приоритет
Фильтрация большого списка → низкий приоритет
```

React сначала поддерживает отзывчивость интерфейса, а затем выполняет transition-обновление.

**На собеседовании:**

> `useTransition` позволяет пометить обновление состояния как неприоритетное. Например, ввод в поиск должен обновляться сразу, а тяжёлый ререндер списка можно выполнить как transition, чтобы интерфейс оставался отзывчивым.

---

### `useDeferredValue`

Позволяет получить **отложенную версию значения**.

```
const [query, setQuery] = useState('');

const deferredQuery = useDeferredValue(query);

return <SearchResults query={deferredQuery} />;
```

Здесь:

```
query
 ↓
обновляется сразу

deferredQuery
 ↓
может обновиться позже
```

Используется, когда у нас есть **тяжёлый UI, зависящий от часто изменяющегося значения**.

**На собеседовании:**

> `useDeferredValue` позволяет использовать отложенную версию значения. Например, пользователь быстро вводит текст в поиск, поле обновляется сразу, а тяжёлый список результатов может обновляться с некоторой задержкой.

**Запомнить:**  
`useTransition` → _«это обновление можно сделать позже»_  
`useDeferredValue` → _«это значение можно использовать позже»_
