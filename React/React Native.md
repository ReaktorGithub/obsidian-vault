React Native — фреймворк для разработки мобильных приложений под iOS и Android с использованием JavaScript или TypeScript и React.
## Базовые особенности

- Нативные компоненты: вместо HTML использует компоненты `View`, `Text`, `Image`, `Pressable`.
    
- React: поддерживает компоненты, props, state, hooks.
    
- Стилизация: стили задаются через JavaScript-объекты, похожие на CSS, но не весь CSS поддерживается. (НЕ CSS-In-JS!!!)
    
- Одна кодовая база: общая логика для iOS и Android с возможностью платформенных различий.
    
- Нативные API: доступ к камере, геолокации, уведомлениям и другим возможностям устройства через API и нативные модули.
    
- Навигация: обычно используется сторонняя библиотека, например React Navigation или Expo Router.
    

## Плюсы

- Общая кодовая база для iOS и Android.
    
- Можно переиспользовать знания React и TypeScript.
    
- Меньше дублирования кода по сравнению с двумя отдельными нативными приложениями.
    
- Доступ к нативным возможностям смартфона.
    
- Быстрая разработка и обновление приложения.
    

## Минусы

- Не весь код можно сделать общим для обеих платформ.
    
- Для сложных нативных функций иногда требуется код на Swift, Objective-C, Kotlin или Java.
    
- Производительность может уступать нативной разработке в некоторых ресурсоёмких сценариях.
    
- Нужно учитывать различия интерфейсов и поведения iOS и Android.
    
- Зависимость от сторонних библиотек и их совместимости.
    

## Для чего используют

- Мобильные приложения интернет-магазинов и банков.
    
- Социальные сети и мессенджеры.
    
- Сервисы доставки, такси и бронирования.
    
- Корпоративные мобильные приложения.
    
- MVP и кроссплатформенные продукты.
    

Главное отличие от React: React используется для создания веб-интерфейсов, обычно через DOM и HTML, а React Native — для мобильных приложений с нативными UI-компонентами.
