SDD (Spec-Driven Development) — подход к разработке, при котором сначала формализуют требования и спецификацию задачи, а затем на их основе пишут код. Особенно полезен при разработке с помощью ИИ-агентов.

### Как работает SDD

1. Specification — описываем, что нужно сделать: требования, сценарии использования, ограничения.
    
2. Planning — проектируем решение: архитектуру, компоненты, API, структуру файлов.
    
3. Tasks — разбиваем работу на конкретные задачи.
    
4. Implementation — агент реализует код по спецификации.
    
5. Validation — проверяем результат тестами и сверяем с требованиями.
    

### Пример для React

Допустим, нужно добавить фильтрацию рекламных кампаний.

Спецификация:

- Фильтрация по статусу кампании и диапазону дат.
    
- Фильтры синхронизируются с URL.
    
- Список обновляется после изменения фильтров.
    
- Состояние загрузки и ошибки отображаются в интерфейсе.
    

План реализации:

- Создать типы фильтров.
    
- Реализовать форму на React Hook Form.
    
- Добавить параметры в URL.
    
- Подключить фильтрацию к API.
    
- Написать тесты.
    

Агент сначала изучает спецификацию и составляет план, затем реализует задачу и проверяет её выполнение.

### Чем SDD отличается от обычной разработки с ИИ

|Обычный подход|SDD|
|---|---|
|Просим агента сразу написать код|Сначала фиксируем требования|
|Агент может самостоятельно додумывать детали|Поведение заранее описано|
|Требования могут теряться в переписке|Спецификация служит источником истины|
|Проверяем, работает ли код в целом|Проверяем соответствие спецификации|

Связь с другими понятиями:

- SDD — методология организации разработки.
    
- Agent loop — цикл действий агента: анализ, изменение кода, проверка и повторение.
    
- Rules — постоянные правила проекта.
    
- Skills — инструкции для выполнения определённых типов задач.
    
- Specification — описание конкретной функциональности, которую нужно реализовать.
    

Главная идея: не просто просить ИИ написать код, а управлять разработкой через проверяемую спецификацию. При этом SDD не гарантирует правильный результат автоматически: спецификация тоже может быть неполной или ошибочной.
