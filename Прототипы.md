### Прототипы в JavaScript (конспект для собеседования)

- **Прототип** — объект, от которого другой объект наследует свойства и методы.
- Если свойство не найдено в объекте, JavaScript ищет его в **цепочке прототипов (prototype chain)**.

### `prototype`

- Свойство **функции-конструктора или класса**.
- Определяет прототип для объектов, созданных через `new`.
- Общий для всех экземпляров.

### `__proto__` (или `[[Prototype]]`)

- Ссылка **конкретного объекта** на его прототип.
- Лучше использовать `Object.getPrototypeOf()` вместо `__proto__`.
