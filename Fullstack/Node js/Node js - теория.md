Node.js - это среда выполнения JavaScript вне браузера, построенная на движке V8, которая позволяет использовать JavaScript для разработки серверных приложений, API, CLI-утилит и других программ.

V8 написан на С++. Работает на Windows, MacOS, Linux. Его задача - скомпилировать и выполнить код на js. Занимается выделением памяти и сборкой мусора.

Libuv (читается как Либ-ю-ви) - это C-библиотека, используемая Node.js для организации асинхронного ввода-вывода, event loop, пула потоков и работы с системными операциями, такими как файловая система, таймеры и сеть.

### Блокирующий ввод-вывод

Блокирующий ввод-вывод в Node.js - это операция, которая останавливает выполнение JavaScript-кода до её завершения, не позволяя обрабатывать другие задачи в основном потоке. Например, `fs.readFileSync()` синхронно читает файл и блокирует Event Loop на время выполнения операции.

## Event Loop в Node.js

**Event Loop** - механизм, который позволяет Node.js выполнять неблокирующие операции ввода-вывода и обрабатывать асинхронные задачи, не блокируя основной поток JavaScript.

### Как работает

1. **Call Stack** - выполняет синхронный JavaScript-код.
    
2. **Node.js / libuv** - организует асинхронные операции ввода-вывода, используя системные механизмы или пул потоков.
    
3. **Event Loop** - проходит по фазам цикла и обрабатывает готовые к выполнению callbacks.
    
4. **Microtasks** - после текущего синхронного кода обрабатываются микрозадачи, например `Promise.then()`. `process.nextTick()` имеет отдельную очередь с более высоким приоритетом в Node.js.
    

### Основные фазы Event Loop

- **Timers** - обработка callbacks таймеров (`setTimeout`, `setInterval`).
    
- **Pending callbacks** - некоторые отложенные системные callbacks.
    
- **Poll** - обработка событий ввода-вывода и ожидание новых событий.
    
- **Check** - выполнение callbacks `setImmediate()`.
    
- **Close callbacks** - обработка событий закрытия, например сокетов.
    

**Важно:** блокирующие синхронные операции останавливают выполнение JavaScript в основном потоке и мешают Event Loop обрабатывать другие задачи.

### Неблокирующий ввод-вывод

Неблокирующий ввод-вывод в Node.js - это подход, при котором выполнение программы не останавливается во время ожидания завершения операций, например чтения файла или ответа от базы данных. Node.js может обрабатывать другие задачи, пока операция выполняется, а результат получать через callback, Promise или `async/await`.

### Демультиплексор событий

**Демультиплексор событий** - механизм, который отслеживает множество источников ввода-вывода и сообщает Event Loop, какие из них готовы к обработке. В Node.js он используется через системные механизмы ОС, например epoll в Linux и kqueue в macOS, позволяя эффективно обрабатывать события без постоянного опроса каждого ресурса.
