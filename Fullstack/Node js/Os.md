**`os` (Operating System)** - встроенный модуль Node.js для получения информации об операционной системе, процессоре, оперативной памяти, сетевых интерфейсах и других параметрах окружения.

### 1. Подключение модуля

```
const os = require('node:os');
```

### 2. Основные методы

**`os.platform()` - тип операционной системы**

```
console.log(os.platform());
// win32, linux, darwin
```

Возвращает платформу, на которой работает Node.js.

**`os.arch()` - архитектура процессора**

```
console.log(os.arch());
// x64, arm64
```

Возвращает архитектуру, для которой собран исполняемый файл Node.js.

**`os.cpus()` - информация о процессорах**

```
console.log(os.cpus());
```

Возвращает массив с информацией о логических ядрах процессора, включая модель, частоту и время работы в разных режимах.

Количество логических ядер можно получить так:

```
console.log(os.cpus().length);
```

**`os.totalmem()` - общий объём оперативной памяти**

```
console.log(os.totalmem() / 1024 ** 3, 'GB');
```

Возвращает общий объём физической памяти в байтах.

**`os.freemem()` - свободная оперативная память**

```
console.log(os.freemem() / 1024 ** 3, 'GB');
```

Возвращает объём свободной физической памяти в байтах.

**`os.homedir()` - домашняя директория пользователя**

```
console.log(os.homedir());
// Например: C:\Users\Oleg
```

**`os.tmpdir()` - директория временных файлов**

```
console.log(os.tmpdir());
```

Возвращает путь к системной директории для временных файлов.

**`os.hostname()` - имя компьютера**

```
console.log(os.hostname());
```

Возвращает сетевое имя устройства.

**`os.uptime()` - время работы системы**

```
console.log(os.uptime());
```

Возвращает количество секунд с момента последнего запуска операционной системы.

**`os.userInfo()` - информация о текущем пользователе**

```
console.log(os.userInfo());
```

Возвращает сведения о пользователе, под которым выполняется процесс, включая имя и домашнюю директорию.

**`os.networkInterfaces()` - сетевые интерфейсы**

```
console.log(os.networkInterfaces());
```

Возвращает информацию о сетевых интерфейсах и их IP-адресах. Может использоваться для диагностики сетевого окружения.

### 3. Пример практического использования

Допустим, нужно получить базовую информацию о сервере для диагностики.

```
const os = require('node:os');

const systemInfo = {
  platform: os.platform(),
  architecture: os.arch(),
  cpuCores: os.cpus().length,
  totalMemoryGB: Math.round(os.totalmem() / 1024 ** 3),
  freeMemoryGB: Math.round(os.freemem() / 1024 ** 3),
  uptimeHours: Math.round(os.uptime() / 3600),
};

console.log(systemInfo);
```

Такой код можно использовать в диагностических скриптах или для сбора базовых сведений об окружении.

### 4. Краткая шпаргалка

|Метод|Назначение|
|---|---|
|`os.platform()`|Тип ОС|
|`os.arch()`|Архитектура процессора|
|`os.cpus()`|Информация о логических ядрах|
|`os.totalmem()`|Общая оперативная память|
|`os.freemem()`|Свободная оперативная память|
|`os.homedir()`|Домашняя директория|
|`os.tmpdir()`|Директория временных файлов|
|`os.hostname()`|Имя компьютера|
|`os.uptime()`|Время работы ОС|
|`os.userInfo()`|Информация о текущем пользователе|
|`os.networkInterfaces()`|Сетевые интерфейсы и IP-адреса|
|`os.EOL`|Символ перевода строки для текущей ОС|

**Коротко для собеседования:** `os` - встроенный модуль Node.js для получения информации об операционной системе и аппаратном окружении. Например, через него можно определить платформу, количество логических ядер, доступную память и сетевые интерфейсы.
