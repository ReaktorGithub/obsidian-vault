Events - механизм событий, позволяющий объектам Node.js генерировать события и уведомлять подписчиков о том, что произошло определённое действие. Для реализации этого механизма используется встроенный модуль `events` и класс `EventEmitter`.

Например, можно генерировать событие при завершении загрузки файла, получении сообщения или изменении состояния приложения.

## 1. EventEmitter

`EventEmitter` - класс, который позволяет создавать события, подписываться на них и вызывать обработчики.

Основные методы:

|Метод|Назначение|
|---|---|
|`on()`|Подписаться на событие|
|`emit()`|Сгенерировать событие|
|`once()`|Подписаться на событие однократно|
|`off()`|Удалить обработчик события|
|`removeListener()`|Удалить конкретный обработчик|
|`removeAllListeners()`|Удалить все обработчики события|
|`listenerCount()`|Узнать количество обработчиков события|

## 2. Пример использования

Создадим собственное событие `orderCreated`.

```
const EventEmitter = require('node:events');

const emitter = new EventEmitter();

// Подписываемся на событие
emitter.on('orderCreated', (orderId) => {
  console.log(`Создан заказ №${orderId}`);
});

// Генерируем событие
emitter.emit('orderCreated', 123);
```

Результат:

```
Создан заказ №123
```

Как это работает:

1. Создаём экземпляр `EventEmitter`.
    
2. Через `on()` регистрируем обработчик события.
    
3. Через `emit()` генерируем событие и передаём данные.
    
4. Все зарегистрированные обработчики этого события вызываются.
    

## 3. Однократная подписка - once()

Метод `once()` запускает обработчик только при первом возникновении события.

```
emitter.once('connected', () => {
  console.log('Первое подключение');
});

emitter.emit('connected');
emitter.emit('connected');
```

Результат:

```
Первое подключение
```

После первого вызова обработчик автоматически удаляется.

## 4. Удаление обработчиков

Для удаления обработчика нужно передать в `off()` ту же функцию, которая использовалась при подписке.

```
function handleMessage(message) {
  console.log(message);
}

emitter.on('message', handleMessage);

emitter.emit('message', 'Привет');

emitter.off('message', handleMessage);

emitter.emit('message', 'Пока');
```

В консоли появится только `Привет`, поскольку перед вторым событием обработчик удалён.

Важно: если передать в `on()` анонимную функцию, для последующего удаления потребуется сохранить ссылку на неё.

## 5. Events в реальных приложениях

События используются во многих встроенных API Node.js:

- HTTP-сервер - событие `request` при получении запроса.
    
- Потоки (Streams) - события `data`, `end`, `error`.
    
- Файловая система - события изменений при использовании `fs.watch()`.
    
- Сетевые соединения - события `connect`, `close`, `data` в соответствующих API.
    

Например, чтение файла через поток:

```
const fs = require('node:fs');

const stream = fs.createReadStream('data.txt');

stream.on('data', (chunk) => {
  console.log('Получена часть файла');
});

stream.on('end', () => {
  console.log('Чтение завершено');
});

stream.on('error', (err) => {
  console.error('Ошибка чтения:', err);
});
```

Здесь поток генерирует события по мере чтения файла, а подписчики реагируют на них.
## Коротко для собеседования

Events в Node.js - механизм событийной коммуникации между компонентами приложения. Для собственных событий используют `EventEmitter`: через `on()` подписываются на событие, через `emit()` генерируют его, через `once()` задают однократную подписку. Обработчики `EventEmitter` вызываются синхронно, поэтому сам механизм событий не равнозначен асинхронности.
