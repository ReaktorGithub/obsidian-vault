**`process`** - глобальный объект Node.js, который предоставляет информацию о текущем процессе и позволяет взаимодействовать с окружением операционной системы.

### Основные возможности

- **Переменные окружения** - `process.env` позволяет получать настройки приложения.
- **Аргументы командной строки** - `process.argv` содержит аргументы, переданные при запуске.
- **Завершение процесса** - `process.exit()` завершает выполнение программы.
- **Код завершения** - `process.exitCode` задаёт код, возвращаемый при завершении процесса.
- **Информация о процессе** - `process.pid` возвращает идентификатор процесса.
- **Рабочая директория** - `process.cwd()` возвращает текущую рабочую директорию.
- **События процесса** - например, `beforeExit`, `exit`, `uncaughtException`.

### Примеры

**1. Переменные окружения**

```
const port = process.env.PORT || 3000;
console.log(port);
```

Позволяет задавать настройки приложения через окружение, например порт сервера.

**2. Аргументы командной строки**

```
console.log(process.argv);
```

При запуске `node app.js hello` массив будет содержать путь к Node.js, путь к файлу `app.js` и аргумент `hello`.

**3. Завершение процесса**

```
process.exitCode = 1;
```

Устанавливает код завершения `1`, который сигнализирует об ошибке. Процесс завершится, когда Node.js закончит работу и не останется активных задач, удерживающих его запущенным.

**4. Текущая рабочая директория**

```
console.log(process.cwd());
```

Возвращает путь к директории, из которой был запущен процесс, а не обязательно к директории, где находится файл.

### Process и Event Loop

Каждое приложение Node.js обычно работает в отдельном процессе со своим экземпляром V8 и основным потоком JavaScript.

Объект `process` позволяет взаимодействовать с этим процессом, а Event Loop управляет выполнением асинхронных callbacks и обработкой событий.

### Коротко для собеседования

`process` - глобальный объект Node.js для взаимодействия с текущим процессом. Через него можно получать переменные окружения и аргументы командной строки, проверять PID, управлять кодом завершения и обрабатывать события жизненного цикла приложения.
