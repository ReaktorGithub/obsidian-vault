Stream (поток) - это механизм обработки данных по частям, без необходимости загружать весь объём данных в память целиком. Потоки используются при чтении и записи файлов, передаче HTTP-данных, работе с сетевыми соединениями и обработке больших объёмов информации.

Например, вместо того чтобы загрузить файл размером 5 ГБ в оперативную память, Node.js может читать его небольшими частями и сразу передавать дальше.

## 1. Виды потоков

В Node.js есть 4 основных типа потоков.

| Тип         | Назначение                                                   | Пример                                      |
| ----------- | ------------------------------------------------------------ | ------------------------------------------- |
| `Readable`  | Чтение данных                                                | Чтение файла через `fs.createReadStream()`  |
| `Writable`  | Запись данных                                                | Запись файла через `fs.createWriteStream()` |
| `Duplex`    | Чтение и запись (readable + writable)                        | TCP-сокет                                   |
| `Transform` | Такой же как Duplex, но может изменять данные по мере чтения | Сжатие файла через `zlib`                   |
### Readable - поток чтения

Позволяет получать данные частями.

```
const fs = require('node:fs');

const stream = fs.createReadStream('input.txt');

stream.on('data', (chunk) => {
  console.log('Получена часть:', chunk);
});

stream.on('end', () => {
  console.log('Чтение завершено');
});
```

Событие `data` вызывается при поступлении очередной части данных (`chunk`). По умолчанию для файлового потока данные обычно представлены объектами `Buffer`.

### Writable - поток записи

Позволяет записывать данные в несколько этапов.

```
const fs = require('node:fs');

const stream = fs.createWriteStream('output.txt');

stream.write('Первая строка\n');
stream.write('Вторая строка\n');

stream.end('Последняя строка\n');

stream.on('finish', () => {
  console.log('Запись завершена');
});
```

Метод `end()` сообщает, что новые данные больше не поступят. После обработки всех записанных данных возникает событие `finish`.

### Duplex - двусторонний поток

Поддерживает чтение и запись независимо друг от друга.

Пример - TCP-сокет, через который приложение может одновременно получать и отправлять данные.

```
const net = require('node:net');

const socket = net.connect(3000, 'localhost');

socket.on('data', (data) => {
  console.log('Получено:', data.toString());
});

socket.write('Привет, сервер!');
```

### Transform - преобразующий поток

Это разновидность `Duplex`, которая преобразует данные во время передачи.

Пример - сжатие текста:

```
const { Transform } = require('node:stream');

const upperCase = new Transform({
  transform(chunk, encoding, callback) {
    callback(null, chunk.toString().toUpperCase());
  }
});

upperCase.on('data', (chunk) => {
  console.log(chunk.toString());
});

upperCase.write('hello');
upperCase.end();
```

Результат: `HELLO`.

## 2. Метод pipe()

Метод `pipe()` соединяет потоки: данные из потока чтения автоматически передаются в поток записи.

```
const fs = require('node:fs');

const readable = fs.createReadStream('input.txt');
const writable = fs.createWriteStream('output.txt');

readable.pipe(writable);
```

В этом примере файл копируется без необходимости загружать его целиком в память.

`pipe()` также помогает регулировать скорость передачи данных, учитывая способность принимающего потока их обрабатывать.

## 3. Метод pipeline()

`pipeline()` - более удобный способ объединения потоков. Он помогает корректно обрабатывать ошибки и завершение всей цепочки.

```
const fs = require('node:fs');
const { pipeline } = require('node:stream');

pipeline(
  fs.createReadStream('input.txt'),
  fs.createWriteStream('output.txt'),
  (err) => {
    if (err) {
      console.error('Ошибка:', err);
    } else {
      console.log('Копирование завершено');
    }
  }
);
```

В современном Node.js также доступен `node:stream/promises`, позволяющий использовать `pipeline()` с `async/await`.

## 4. Что такое chunk и Buffer?

- `chunk` - очередная порция данных, поступившая в поток.
    
- `Buffer` - объект для работы с бинарными данными, например байтами файла или сетевого сообщения.
    

Пример:

```
stream.on('data', (chunk) => {
  console.log(chunk.length); // размер части в байтах
  console.log(chunk.toString()); // преобразование в текст
});
```

Размер части зависит от типа потока и его настроек. Например, у файловых потоков можно задать `highWaterMark` - пороговый размер внутреннего буфера.

## 5. Backpressure - управление нагрузкой

Backpressure - механизм, который не позволяет быстрому потоку бесконтрольно передавать данные медленному получателю.

Представим, что файл читается быстрее, чем записывается на диск. Без управления потоком данные могут накапливаться в памяти.

При использовании `pipe()` Node.js автоматически приостанавливает чтение, когда буфер получателя заполнен, и возобновляет его, когда появляется место.

При ручной записи нужно учитывать возвращаемое значение `write()`:

```
const canContinue = writable.write(data);

if (!canContinue) {
  writable.once('drain', () => {
    // Буфер освободил место, можно продолжать запись
  });
}
```

Если `write()` возвращает `false`, это означает, что дальнейшую запись стоит приостановить до события `drain`.

## 6. Основные события потоков

|Событие|Значение|
|---|---|
|`data`|Получена очередная часть данных|
|`end`|Поток чтения закончил передавать данные|
|`finish`|Поток записи завершил обработку записанных данных|
|`error`|Произошла ошибка|
|`close`|Поток или связанный ресурс закрыт|
|`drain`|Буфер потока записи освободил достаточно места для продолжения записи|

Важно различать `end` и `finish`: первое относится к чтению, второе - к записи.

## 7. Практический пример: чтение, сжатие и запись

Можно объединить несколько потоков, чтобы прочитать файл, сжать его и записать результат.

```
const fs = require('node:fs');
const zlib = require('node:zlib');
const { pipeline } = require('node:stream');

pipeline(
  fs.createReadStream('input.txt'),
  zlib.createGzip(),
  fs.createWriteStream('input.txt.gz'),
  (err) => {
    if (err) {
      console.error(err);
      return;
    }

    console.log('Файл сжат');
  }
);
```

Данные проходят последовательно через три этапа:

1. `createReadStream()` читает исходный файл.
    
2. `createGzip()` сжимает данные.
    
3. `createWriteStream()` записывает результат.
    

При этом весь файл не требуется держать в памяти.

## 8. Когда использовать streams?

- Обработка больших файлов.
    
- Передача файлов клиенту в HTTP-ответе.
    
- Загрузка файлов на сервер.
    
- Работа с TCP-соединениями.
    
- Сжатие и распаковка данных.
    
- Обработка больших объёмов данных с ограниченным потреблением памяти.
    

Главное преимущество потоков - экономия памяти и возможность обрабатывать данные по мере их поступления, не дожидаясь полной загрузки.
