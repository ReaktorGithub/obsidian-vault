Nginx - веб-сервер и обратный прокси-сервер, который принимает HTTP/HTTPS-запросы от клиентов и может отдавать статические файлы, перенаправлять запросы на backend и распределять нагрузку между серверами.

### Основные функции

- Веб-сервер - отдаёт статические файлы: HTML, CSS, JS, изображения.
    
- Reverse proxy (обратный прокси) - принимает запросы от клиента и передаёт их backend-серверу, например Node.js.
    
- Load balancing - распределяет запросы между несколькими backend-серверами.
    
- HTTPS termination - принимает HTTPS-соединения, обрабатывает TLS и передаёт запросы внутренним серверам.
    
- Кэширование - сохраняет копии ответов, чтобы ускорить повторные запросы и снизить нагрузку на backend.
    
### Как работает Nginx вместе с Node.js

Клиент (браузер)

HTTP / HTTPS-запрос

Nginx

Принимает запрос, отдаёт статику или проксирует его

Node.js / Express

Бизнес-логика, API, работа с БД

База данных

PostgreSQL / MySQL

Например, пользователь открывает `https://example.com/api/users`. Nginx принимает запрос и перенаправляет его на Node.js-сервер. Express обрабатывает запрос, получает данные из базы и возвращает ответ через Nginx браузеру.

### Пример конфигурации

```
server {
    listen 80;
    server_name example.com;

    location / {
        root /var/www/frontend;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

Здесь Nginx отдаёт frontend-файлы из `/var/www/frontend`, а запросы к `/api/` перенаправляет на приложение Node.js, работающее на порту `3000`.

### Зачем нужен Nginx, если есть Node.js?

Node.js умеет самостоятельно принимать HTTP-запросы, но Nginx удобно использовать как внешний сервер, который:

- принимает соединения от клиентов;
    
- обслуживает статические файлы;
    
- управляет HTTPS;
    
- распределяет нагрузку между несколькими экземплярами приложения;
    
- скрывает внутренние адреса и порты backend-серверов.
    

Коротко для собеседования: Nginx - веб-сервер и reverse proxy, который принимает клиентские запросы, обслуживает статику, проксирует API-запросы на backend и может выполнять балансировку нагрузки и TLS-терминацию.
