`WHERE` — условие, которое фильтрует строки и возвращает только те записи, которые ему соответствуют.

```
SELECT *
FROM users
WHERE age > 18;
```

Вернёт пользователей старше 18 лет.

## Операторы сравнения

|Оператор|Значение|Пример|
|---|---|---|
|`=`|Равно|`age = 18`|
|`<>` или `!=`|Не равно|`age <> 18`|
|`>`|Больше|`age > 18`|
|`<`|Меньше|`age < 18`|
|`>=`|Больше или равно|`age >= 18`|
|`<=`|Меньше или равно|`age <= 18`|

## Другие операторы условий

```
-- В диапазоне включительно
WHERE age BETWEEN 18 AND 30

-- Совпадает / не совпадает с одним из значений (тоже самое, что несколько OR)
WHERE city IN ('Москва', 'Тула')
WHERE city NOT IN ('Москва', 'Тула')

-- Совпадает с шаблоном
WHERE name LIKE 'А%'

-- Значение отсутствует
WHERE age IS NULL

-- Значение присутствует
WHERE age IS NOT NULL
```

`LIKE` использует шаблоны:

- `%` — любое количество символов.
    
- `_` — ровно один символ.
    

В PostgreSQL `ILIKE` работает как `LIKE`, но без учёта регистра.

## Логические операторы

```
-- Оба условия должны выполняться
WHERE age >= 18 AND city = 'Москва'

-- Достаточно одного условия
WHERE city = 'Москва' OR city = 'Тула'

-- Отрицание условия
WHERE NOT (age < 18)
```

Важно: для проверки `NULL` нельзя использовать `= NULL` или `!= NULL`. Используй `IS NULL` и `IS NOT NULL`.
