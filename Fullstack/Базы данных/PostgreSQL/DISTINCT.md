`DISTINCT` — убирает дубликаты из результата запроса, оставляя только уникальные значения или комбинации значений.
### Пример

```
SELECT DISTINCT city
FROM users;
```

Возвращает список уникальных городов пользователей.

### Несколько столбцов

```
SELECT DISTINCT city, country
FROM users;
```

Возвращает уникальные комбинации городов и стран. Если пара `city` + `country` повторяется, она выводится один раз.

### DISTINCT ON

`DISTINCT ON` — возвращает по одной записи для каждого уникального значения указанного столбца или набора столбцов. Это особенность PostgreSQL.

```
SELECT DISTINCT ON (city) city, name, created_at
FROM users
ORDER BY city, created_at DESC;
```

Возвращает по одному пользователю на каждый город — с самой поздней датой `created_at`.

**Важно:** при использовании `DISTINCT ON` порядок `ORDER BY` определяет, какая запись будет выбрана для каждой группы. Обычно столбцы из `DISTINCT ON` должны идти первыми в `ORDER BY`.
