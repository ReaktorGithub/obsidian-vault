## Добавление и получение данных

Добавим пользователя:

```
INSERT INTO users (name, email, age)
VALUES ('Олег', 'oleg@example.com', 25);
```

Получим всех пользователей:

```
SELECT * FROM users;
```

Изменим возраст:

```
UPDATE users
SET age = 26
WHERE id = 1;
```

Удалим пользователя:

```
DELETE FROM users
WHERE id = 1;
```

Важно: `CREATE DATABASE` создаёт базу данных, а `CREATE TABLE` создаёт таблицу внутри текущей базы. Перед созданием таблицы нужно подключиться к нужной базе данных.

Экранирование символов:
VALUES ('Oleg''s');

Добавить несколько значений:

```
INSERT INTO users (name, email, age)
VALUES
('Олег', 'oleg@example.com', 25),
('Вася', 'vasya@example.com', 30);
```
## Краткая шпаргалка

|Команда|Назначение|
|---|---|
|`ALTER TABLE ... RENAME TO`|Переименовать таблицу|
|`ALTER TABLE ... RENAME COLUMN ... TO`|Переименовать столбец|
|`ADD COLUMN`|Добавить столбец|
|`ALTER COLUMN ... TYPE`|Изменить тип данных|
|`ALTER COLUMN ... SET DEFAULT`|Установить значение по умолчанию|
|`ALTER COLUMN ... DROP DEFAULT`|Удалить значение по умолчанию|
|`ALTER COLUMN ... SET NOT NULL`|Запретить `NULL`|
|`ALTER COLUMN ... DROP NOT NULL`|Разрешить `NULL`|
|`DROP COLUMN`|Удалить столбец|
|`DROP TABLE`|Удалить таблицу|
|`TRUNCATE TABLE`|Удалить все строки таблицы|

`ALTER TABLE` — команда для изменения структуры существующей таблицы: добавления, удаления и изменения столбцов, переименования и управления ограничениями.

## RENAME — переименование

Переименовать таблицу:

```
ALTER TABLE users
RENAME TO customers;
```

Переименовать столбец:

```
ALTER TABLE users
RENAME COLUMN name TO full_name;
```

## ADD COLUMN — добавление столбца

```
ALTER TABLE users
ADD COLUMN age INTEGER;
```

Добавить столбец с ограничением и значением по умолчанию:

```
ALTER TABLE users
ADD COLUMN is_active BOOLEAN NOT NULL DEFAULT TRUE;
```

Добавить столбец, только если он ещё не существует:

```
ALTER TABLE users
ADD COLUMN IF NOT EXISTS age INTEGER;
```

## ALTER COLUMN — изменение столбца

`ALTER COLUMN` позволяет изменять тип данных, значение по умолчанию и ограничения столбца.

### SET DATA TYPE — изменение типа данных

```
ALTER TABLE users
ALTER COLUMN age SET DATA TYPE BIGINT;
```

Можно использовать сокращённую форму `TYPE`:

```
ALTER TABLE users
ALTER COLUMN age TYPE BIGINT;
```

При необходимости можно преобразовать существующие значения с помощью `USING`:

```
ALTER TABLE users
ALTER COLUMN age TYPE TEXT
USING age::TEXT;
```

`USING` задаёт выражение для преобразования существующих значений в новый тип.

### SET DEFAULT — установка значения по умолчанию

```
ALTER TABLE users
ALTER COLUMN age SET DEFAULT 18;
```

### DROP DEFAULT — удаление значения по умолчанию

```
ALTER TABLE users
ALTER COLUMN age DROP DEFAULT;
```

### SET NOT NULL — запрет NULL

```
ALTER TABLE users
ALTER COLUMN name SET NOT NULL;
```

Команда завершится ошибкой, если в столбце уже есть значения `NULL`.

### DROP NOT NULL — разрешение NULL

```
ALTER TABLE users
ALTER COLUMN name DROP NOT NULL;
```

## DROP COLUMN — удаление столбца

```
ALTER TABLE users
DROP COLUMN age;
```

Удалить столбец, только если он существует:

```
ALTER TABLE users
DROP COLUMN IF EXISTS age;
```

`CASCADE` позволяет удалить также зависимые объекты:

```
ALTER TABLE users
DROP COLUMN age CASCADE;
```

**Осторожно:** `CASCADE` может привести к удалению других объектов базы данных, зависящих от этого столбца.

## DROP TABLE — удаление таблицы

```
DROP TABLE users;
```

Удалить, только если таблица существует:

```
DROP TABLE IF EXISTS users;
```

Удалить таблицу вместе с зависимыми объектами:

```
DROP TABLE users CASCADE;
```

## TRUNCATE — очистка таблицы

`TRUNCATE` удаляет **все строки таблицы**, но сохраняет её структуру.

```
TRUNCATE TABLE users;
```

Очистить таблицу и сбросить счётчики последовательностей, связанных со столбцами:

```
TRUNCATE TABLE users RESTART IDENTITY;
```

Очистить несколько таблиц:

```
TRUNCATE TABLE users, orders;
```

Очистить таблицу вместе с таблицами, ссылающимися на неё через внешние ключи:

```
TRUNCATE TABLE users CASCADE;
```

**Важно:** `TRUNCATE` не поддерживает `WHERE`. Чтобы удалить только определённые строки, используй `DELETE`.

## DROP, DELETE и TRUNCATE — различия

|Команда|Что удаляет|Структура таблицы|WHERE|
|---|---|---|---|
|`DELETE`|Строки|Сохраняется|Да|
|`TRUNCATE`|Все строки|Сохраняется|Нет|
|`DROP TABLE`|Таблицу целиком|Удаляется|Нет|

Примеры:

```
-- Удалить определённые строки
DELETE FROM users WHERE age < 18;

-- Удалить все строки
TRUNCATE TABLE users;

-- Удалить таблицу целиком
DROP TABLE users;
```
