**Функция (FUNCTION)** - это именованный блок кода, который выполняет определённые действия и может возвращать значение или набор строк. Функции позволяют переиспользовать логику, выполнять вычисления и обрабатывать данные непосредственно в базе данных.

В PostgreSQL функции можно писать на SQL, PL/pgSQL и других поддерживаемых языках.

## Создание функции

Для создания функции используется `CREATE FUNCTION`.

```
CREATE FUNCTION sum_numbers(a INTEGER, b INTEGER)
RETURNS INTEGER
LANGUAGE SQL
AS $$
    SELECT a + b;
$$;
```

Разберём конструкцию:

- `CREATE FUNCTION` - создание функции.
- `sum_numbers` - имя функции.
- `a INTEGER, b INTEGER` - входные параметры.
- `RETURNS INTEGER` - тип возвращаемого значения.
- `LANGUAGE SQL` - язык реализации.
- `AS $$ ... $$` - тело функции.

Вызов:

```
SELECT sum_numbers(10, 20);
```

Результат:

|sum_numbers|
|---|
|30|

Функцию можно использовать и внутри других запросов:

```
SELECT
    id,
    salary,
    sum_numbers(salary, 1000) AS increased_salary
FROM employees;
```

Здесь к зарплате каждого сотрудника прибавляется 1000.

## Языки функций

### SQL

Подходит для функций, которые реализуют логику с помощью SQL-запросов.

```
CREATE FUNCTION get_employee_count()
RETURNS BIGINT
LANGUAGE SQL
AS $$
    SELECT COUNT(*) FROM employees;
$$;
```

Вызов:

```
SELECT get_employee_count();
```

### PL/pgSQL

Процедурный язык PostgreSQL. Позволяет использовать переменные, условия, циклы, обработку исключений и несколько последовательных SQL-команд.

```
CREATE FUNCTION get_salary_level(salary NUMERIC)
RETURNS TEXT
LANGUAGE plpgsql
AS $$
BEGIN
    IF salary >= 150000 THEN
        RETURN 'Высокая';
    ELSIF salary >= 100000 THEN
        RETURN 'Средняя';
    ELSE
        RETURN 'Низкая';
    END IF;
END;
$$;
```

Вызов:

```
SELECT get_salary_level(120000);
```

Результат: `Средняя`.

**Разница:** SQL удобен для запросов и простых вычислений, а PL/pgSQL - для процедурной логики с условиями, циклами и обработкой ошибок.

## Параметры функций

Функции могут принимать параметры разных режимов.

|Режим|Назначение|
|---|---|
|`IN`|Входной параметр. Используется по умолчанию|
|`OUT`|Выходной параметр|
|`INOUT`|Параметр одновременно для входа и выхода|
|`VARIADIC`|Приём переменного количества аргументов одного типа|

### IN

```
CREATE FUNCTION multiply(a INTEGER, b INTEGER)
RETURNS INTEGER
LANGUAGE SQL
AS $$
    SELECT a * b;
$$;
```

`IN` можно не указывать, поскольку это режим по умолчанию.

### OUT

Позволяет вернуть несколько значений через выходные параметры.

```
CREATE FUNCTION get_stats(
    OUT employee_count BIGINT,
    OUT average_salary NUMERIC
)
LANGUAGE SQL
AS $$
    SELECT COUNT(*), AVG(salary)
    FROM employees;
$$;
```

Вызов:

```
SELECT * FROM get_stats();
```

Результат будет содержать два столбца: количество сотрудников и среднюю зарплату.

### INOUT

Параметр принимает начальное значение и возвращает изменённое.

```
CREATE FUNCTION increase_value(INOUT value INTEGER)
LANGUAGE plpgsql
AS $$
BEGIN
    value := value + 10;
END;
$$;
```

Вызов:

```
SELECT increase_value(5);
```

Результат: `15`.

### VARIADIC

Позволяет передать переменное количество аргументов.

```
CREATE FUNCTION sum_all(VARIADIC nums INTEGER[])
RETURNS INTEGER
LANGUAGE SQL
AS $$
    SELECT COALESCE(SUM(n), 0)::INTEGER
    FROM unnest(nums) AS n;
$$;
```

Вызов:

```
SELECT sum_all(1, 2, 3, 4, 5);
```

Результат: `15`.

## Возвращаемые значения

Функция может возвращать разные типы данных.

### Скалярное значение

Одно значение: число, строку, дату и т. д.

```
CREATE FUNCTION get_double(n INTEGER)
RETURNS INTEGER
LANGUAGE SQL
AS $$
    SELECT n * 2;
$$;
```

### RETURNS TABLE

Позволяет вернуть набор строк с определёнными столбцами.

```
CREATE FUNCTION get_it_employees()
RETURNS TABLE (
    employee_id INTEGER,
    employee_name TEXT,
    employee_salary NUMERIC
)
LANGUAGE SQL
AS $$
    SELECT id, name::TEXT, salary
    FROM employees
    WHERE department = 'IT';
$$;
```

Вызов:

```
SELECT * FROM get_it_employees();
```

Результат будет похож на результат обычного `SELECT`.

### RETURNS SETOF

Позволяет вернуть набор значений определённого типа.

```
CREATE FUNCTION get_all_salaries()
RETURNS SETOF NUMERIC
LANGUAGE SQL
AS $$
    SELECT salary
    FROM employees;
$$;
```

Вызов:

```
SELECT * FROM get_all_salaries();
```

Функция вернёт несколько строк с зарплатами.

**Разница:**

- `RETURNS TABLE` - набор строк с заданными столбцами.
- `RETURNS SETOF type` - набор значений указанного типа, в том числе составного типа.
- `RETURNS type` - одно значение указанного типа.

## Переменные и RETURN в PL/pgSQL

В PL/pgSQL можно объявлять переменные в секции `DECLARE`.

```
CREATE FUNCTION calculate_bonus(salary NUMERIC)
RETURNS NUMERIC
LANGUAGE plpgsql
AS $$
DECLARE
    bonus NUMERIC;
BEGIN
    bonus := salary * 0.1;

    RETURN bonus;
END;
$$;
```

- `DECLARE` - объявление переменных.
- `:=` - присваивание значения.
- `BEGIN ... END` - блок команд.
- `RETURN` - возврат результата.

Вызов:

```
SELECT calculate_bonus(100000);
```

Результат: `10000`.

Для функций, возвращающих набор строк, используются механизмы вроде `RETURN QUERY`, `RETURN NEXT` и `RETURN`, в зависимости от способа реализации.

## Условия и циклы в функциях

PL/pgSQL поддерживает обычные управляющие конструкции.

### IF / ELSIF / ELSE

```
IF salary > 100000 THEN
    RETURN 'Высокая';
ELSIF salary > 50000 THEN
    RETURN 'Средняя';
ELSE
    RETURN 'Низкая';
END IF;
```

### CASE

```
CASE department
    WHEN 'IT' THEN
        RETURN 'Разработка';
    WHEN 'HR' THEN
        RETURN 'Кадры';
    ELSE
        RETURN 'Другой отдел';
END CASE;
```

### Цикл FOR

```
CREATE FUNCTION sum_range(n INTEGER)
RETURNS INTEGER
LANGUAGE plpgsql
AS $$
DECLARE
    total INTEGER := 0;
    i INTEGER;
BEGIN
    FOR i IN 1..n LOOP
        total := total + i;
    END LOOP;

    RETURN total;
END;
$$;
```

Вызов:

```
SELECT sum_range(5);
```

Результат: `15`.

Для обычных вычислений и обработки наборов данных часто лучше использовать SQL-запросы, а не циклы. Циклы нужны, когда действительно требуется последовательная обработка.

## Обработка ошибок

В PL/pgSQL можно перехватывать исключения с помощью `EXCEPTION`.

```
CREATE FUNCTION safe_divide(a NUMERIC, b NUMERIC)
RETURNS NUMERIC
LANGUAGE plpgsql
AS $$
BEGIN
    RETURN a / b;

EXCEPTION
    WHEN division_by_zero THEN
        RETURN NULL;
END;
$$;
```

Вызов:

```
SELECT safe_divide(10, 0);
```

Результат: `NULL`.

Однако не всегда нужно обрабатывать ошибку таким способом. Иногда правильнее вернуть понятную ошибку вызывающему коду.

## Атрибуты функций

При создании функций можно указывать характеристики, влияющие на оптимизацию и поведение.

### IMMUTABLE

Результат зависит только от аргументов и не меняется при повторном вызове с теми же аргументами.

```
CREATE FUNCTION square(n INTEGER)
RETURNS INTEGER
LANGUAGE SQL
IMMUTABLE
AS $$
    SELECT n * n;
$$;
```

### STABLE

Результат гарантированно одинаков для одинаковых аргументов в пределах одного SQL-оператора при неизменном снимке данных.

Например, `CURRENT_TIMESTAMP` ведёт себя как стабильное значение в рамках транзакции.

### VOLATILE

Результат может меняться даже при одинаковых аргументах. Это категория по умолчанию.

Например, `random()` возвращает случайные значения.

|Атрибут|Гарантия|
|---|---|
|`IMMUTABLE`|Результат зависит только от аргументов|
|`STABLE`|Результат стабилен в пределах одного SQL-оператора|
|`VOLATILE`|Результат может меняться при каждом вызове|

Эти атрибуты - обещания разработчика планировщику PostgreSQL. Нельзя объявлять функцию `IMMUTABLE`, если она читает изменяемые таблицы или зависит от текущего времени.

Другие полезные характеристики:

- `STRICT` - функция не вызывается, если хотя бы один аргумент равен `NULL`; вместо этого возвращается `NULL`.
- `PARALLEL SAFE`, `PARALLEL RESTRICTED`, `PARALLEL UNSAFE` - характеристики допустимости выполнения в параллельном плане.
- `SECURITY INVOKER` - функция выполняется с правами вызывающего пользователя; это поведение по умолчанию.
- `SECURITY DEFINER` - функция выполняется с правами её владельца. Требует осторожности при работе с правами доступа.

## Удаление и изменение функций

### Удаление

```
DROP FUNCTION sum_numbers(INTEGER, INTEGER);
```

Типы аргументов указываются, чтобы PostgreSQL мог определить конкретную перегрузку функции.

### Изменение определения

```
CREATE OR REPLACE FUNCTION sum_numbers(a INTEGER, b INTEGER)
RETURNS INTEGER
LANGUAGE SQL
AS $$
    SELECT a + b + 1;
$$;
```

`CREATE OR REPLACE FUNCTION` позволяет заменить реализацию существующей функции с той же сигнатурой. Однако он не предназначен для произвольного изменения типов уже существующих параметров или возвращаемого типа.

### Перегрузка

В PostgreSQL можно создавать несколько функций с одним именем, если они различаются допустимыми сигнатурами.

```
CREATE FUNCTION calculate(a INTEGER, b INTEGER)
RETURNS INTEGER
LANGUAGE SQL
AS $$
    SELECT a + b;
$$;

CREATE FUNCTION calculate(a NUMERIC, b NUMERIC)
RETURNS NUMERIC
LANGUAGE SQL
AS $$
    SELECT a * b;
$$;
```

Вызов с аргументами типа `INTEGER` и `NUMERIC` может выбрать разные функции в зависимости от типов аргументов и правил разрешения перегрузок.

## Функции, процедуры и триггеры: в чём разница?

|Механизм|Назначение|Как вызывается|
|---|---|---|
|`FUNCTION`|Вычисления, получение значений, обработка данных|Обычно через `SELECT`|
|`PROCEDURE`|Выполнение последовательности действий|Через `CALL`|
|`TRIGGER`|Автоматический запуск логики при определённых событиях в таблице или представлении|Срабатывает автоматически|

### Функция

```
SELECT sum_numbers(2, 3);
```

Функция возвращает результат и может использоваться в SQL-выражениях.

### Процедура

```
CREATE PROCEDURE update_salary(
    employee_id INTEGER,
    new_salary NUMERIC
)
LANGUAGE SQL
AS $$
    UPDATE employees
    SET salary = new_salary
    WHERE id = employee_id;
$$;
```

Вызов:

```
CALL update_salary(1, 150000);
```

Процедура может выполнять действия без возвращения значения через обычный `RETURNS`. В отличие от функции, процедура в некоторых условиях позволяет управлять транзакциями с помощью `COMMIT` и `ROLLBACK`.

### Триггер

Триггер привязывается к событию, например `INSERT`, `UPDATE` или `DELETE`. В PostgreSQL триггер обычно вызывает специальную триггерную функцию, которая возвращает `trigger`.

Пример использования - автоматически записывать историю изменений зарплаты сотрудника.

## Встроенные функции PostgreSQL

PostgreSQL содержит множество готовых функций.

|Категория|Примеры|Назначение|
|---|---|---|
|Строковые|`LENGTH()`, `UPPER()`, `LOWER()`, `CONCAT()`, `SUBSTRING()`|Работа со строками|
|Числовые|`ROUND()`, `ABS()`, `CEIL()`, `FLOOR()`, `POWER()`|Математические операции|
|Даты и время|`NOW()`, `CURRENT_DATE`, `AGE()`, `EXTRACT()`|Работа с датами и временем|
|Агрегатные|`COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`|Вычисления по набору строк|
|Работа с `NULL`|`COALESCE()`, `NULLIF()`|Обработка отсутствующих значений|
|Преобразование типов|`CAST()`, `TO_CHAR()`, `TO_DATE()`|Преобразование и форматирование|
|JSON|`JSONB_BUILD_OBJECT()`, `JSONB_ARRAY_ELEMENTS()`|Работа с JSON|
|Оконные|`ROW_NUMBER()`, `RANK()`, `LAG()`, `LEAD()`|Вычисления по окну строк|

Например:

```
SELECT
    UPPER(name) AS uppercase_name,
    ROUND(salary / 12, 2) AS monthly_salary,
    CURRENT_DATE AS today
FROM employees;
```

Здесь встроенные функции преобразуют имя в верхний регистр, рассчитывают условную месячную зарплату и возвращают текущую дату.

## Кратко для собеседования

**Функция PostgreSQL** - это именованный блок кода, который принимает параметры и возвращает значение или набор строк. Функции создаются через `CREATE FUNCTION`, могут быть написаны на SQL или PL/pgSQL и использоваться внутри SQL-запросов.

Основные вещи, которые стоит знать:

- `CREATE FUNCTION`, `CREATE OR REPLACE FUNCTION`, `DROP FUNCTION`.
- `RETURNS`, `RETURNS TABLE`, `RETURNS SETOF`.
- Параметры `IN`, `OUT`, `INOUT`, `VARIADIC`.
- Переменные, условия, циклы и обработка исключений в PL/pgSQL.
- Атрибуты `IMMUTABLE`, `STABLE`, `VOLATILE`, `STRICT`.
- Различия между функциями, процедурами и триггерами.
- Встроенные функции для строк, чисел, дат, агрегатов и JSON.
