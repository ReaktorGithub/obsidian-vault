В PostgreSQL базу данных и таблицу можно создать с помощью SQL-команд.

## Создание базы данных

```
CREATE DATABASE my_database;
```

Подключиться к созданной базе можно через pgAdmin или командную строку `psql`:

```
psql -d my_database
```

Внутри `psql` переключиться на другую базу можно командой `\c my_database`.

## Создание таблицы

Например, создадим таблицу пользователей:

```
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE,
    age INTEGER,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

Что здесь используется:

- `SERIAL` — автоматически увеличивающееся целое число.
    
- `PRIMARY KEY` — первичный ключ, уникально идентифицирующий запись.
    
- `VARCHAR(100)` — строка длиной до 100 символов.
    
- `NOT NULL` — поле обязательно для заполнения.
    
- `UNIQUE` — значения не должны повторяться.
    
- `INTEGER` — целое число.
    
- `TIMESTAMP` — дата и время.
    
- `DEFAULT CURRENT_TIMESTAMP` — текущая дата и время по умолчанию.
    


`IF EXISTS` и `IF NOT EXISTS`

```
-- Создать таблицу, если она не существует
CREATE TABLE IF NOT EXISTS users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100)
);

-- Удалить таблицу, если она существует
DROP TABLE IF EXISTS users;

-- Удалить базу данных, если она существует
DROP DATABASE IF EXISTS my_database;

-- Добавить столбец, если он не существует
ALTER TABLE users
ADD COLUMN IF NOT EXISTS age INTEGER;
```

**Важно:** `IF EXISTS` проверяет существование объекта, а `IF NOT EXISTS` — отсутствие объекта перед созданием или добавлением.
