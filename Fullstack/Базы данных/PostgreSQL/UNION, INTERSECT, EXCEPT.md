### UNION

`UNION` — объединяет результаты нескольких `SELECT` в один набор строк и удаляет дубликаты.

### Пример

Есть таблица `users`:

|name|
|---|
|Олег|
|Анна|

И таблица `employees`:

|name|
|---|
|Анна|
|Иван|

```
SELECT name FROM users
UNION
SELECT name FROM employees;
```

Результат:

|name|
|---|
|Олег|
|Анна|
|Иван|

Имя «Анна» встречается в обеих таблицах, но в результате выводится один раз.

### UNION ALL

`UNION ALL` объединяет результаты, сохраняя дубликаты.

```
SELECT name FROM users
UNION ALL
SELECT name FROM employees;
```

Результат:

|name|
|---|
|Олег|
|Анна|
|Анна|
|Иван|

### Условия использования

- Количество столбцов в обоих запросах должно совпадать.
    
- Типы данных соответствующих столбцов должны быть совместимы.
    
- Названия столбцов итогового результата берутся из первого `SELECT`.
    
- `ORDER BY` в конце сортирует общий результат.
    

```
SELECT name FROM users
UNION
SELECT name FROM employees
ORDER BY name;
```

Коротко: `UNION` объединяет результаты и убирает дубликаты, а `UNION ALL` объединяет результаты без удаления дубликатов. `UNION ALL` обычно работает быстрее, поскольку не требует устранять повторяющиеся строки.

### INTERSECT

`INTERSECT` — возвращает только те строки, которые присутствуют в результатах обоих запросов. Дубликаты удаляются.

### Пример

Таблица `users`:

|name|
|---|
|Олег|
|Анна|
|Иван|

Таблица `employees`:

|name|
|---|
|Анна|
|Иван|
|Мария|

```
SELECT name FROM users
INTERSECT
SELECT name FROM employees;
```

Результат:

|name|
|---|
|Анна|
|Иван|

В результате остаются только имена, которые есть в обеих таблицах.

### INTERSECT ALL

`INTERSECT ALL` сохраняет дубликаты в пределах количества повторений, присутствующих в обоих результатах.

```
SELECT name FROM users
INTERSECT ALL
SELECT name FROM employees;
```

Коротко:

- `UNION` — строки из обоих запросов.
    
- `INTERSECT` — только общие строки.
    
- `EXCEPT` — строки из первого запроса, которых нет во втором.
    

Количество столбцов должно совпадать, а типы данных соответствующих столбцов должны быть совместимы.

### EXCEPT

`EXCEPT` — возвращает строки из результата первого `SELECT`, которых нет в результате второго `SELECT`. Дубликаты удаляются.

### Пример

Таблица `users`:

|name|
|---|
|Олег|
|Анна|
|Иван|

Таблица `employees`:

|name|
|---|
|Анна|
|Мария|

```
SELECT name FROM users
EXCEPT
SELECT name FROM employees;
```

Результат:

|name|
|---|
|Олег|
|Иван|

Анна исключена, потому что присутствует в обеих таблицах.

### EXCEPT ALL

`EXCEPT ALL` сохраняет дубликаты, вычитая количество совпадений во втором результате из количества строк в первом.

```
SELECT name FROM users
EXCEPT ALL
SELECT name FROM employees;
```

### Кратко

- `UNION` — объединяет результаты.
    
- `INTERSECT` — возвращает общие строки.
    
- `EXCEPT` — возвращает строки первого запроса, которых нет во втором.
    

Важно: порядок запросов имеет значение: `A EXCEPT B` не обязательно равно `B EXCEPT A`.
