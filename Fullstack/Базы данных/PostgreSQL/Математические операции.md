## Математические операции в PostgreSQL

|Оператор|Описание|Пример|Результат|
|---|---|---|---|
|`+`|Сложение|`SELECT 5 + 3;`|`8`|
|`-`|Вычитание|`SELECT 5 - 3;`|`2`|
|`*`|Умножение|`SELECT 5 * 3;`|`15`|
|`/`|Деление|`SELECT 10 / 3;`|`3`|
|`%`|Остаток от деления|`SELECT 10 % 3;`|`1`|
|`^`|Возведение в степень|`SELECT 2 ^ 3;`|`8`|
|`\|/`|Квадратный корень|`SELECT \|/ 25;`|`5`|
|`!!`|Факториал|`SELECT 5 !!;`|`120`|

**Важно:**

- При делении целых чисел (`INTEGER`) дробная часть отбрасывается: `10 / 3 = 3`.
- Чтобы получить дробный результат, используй `SELECT 10.0 / 3;`.
- Для финансовых вычислений предпочтителен тип `NUMERIC`, поскольку он обеспечивает точную десятичную арифметику.

### Примеры с данными таблицы

Можно применять математические операции к столбцам:

```
SELECT price * quantity AS total
FROM orders;
```

Вычисляет стоимость заказа как произведение цены на количество.

```
SELECT price * 0.9 AS discounted_price
FROM products;
```

Вычисляет цену со скидкой 10%.

```
SELECT AVG(price) AS average_price,
       SUM(price) AS total_price,
       MAX(price) AS max_price,
       MIN(price) AS min_price
FROM products;
```

Агрегатные функции:

- `AVG()` — среднее значение.
- `SUM()` — сумма.
- `MAX()` — максимальное значение.
- `MIN()` — минимальное значение.
- `COUNT()` — количество записей.
