`ORDER BY` — сортирует строки результата запроса по одному или нескольким столбцам.

### Направление сортировки

```
-- По возрастанию (по умолчанию)
SELECT * FROM users
ORDER BY age ASC;

-- По убыванию
SELECT * FROM users
ORDER BY age DESC;
```

- `ASC` — по возрастанию.
    
- `DESC` — по убыванию.
    

### Сортировка по нескольким столбцам

```
SELECT * FROM users
ORDER BY city ASC, age DESC;
```

Сначала сортирует по городу по возрастанию, затем внутри каждого города — по возрасту по убыванию.

### Сортировка с NULL

```
SELECT * FROM users
ORDER BY age ASC NULLS LAST;
```

- `NULLS FIRST` — значения `NULL` в начале.
    
- `NULLS LAST` — значения `NULL` в конце.
    

По умолчанию `NULL` располагаются в конце при `ASC` и в начале при `DESC`.

### Сортировка с ограничением результата

```
SELECT * FROM users
ORDER BY age DESC
LIMIT 5;
```

Возвращает 5 пользователей с наибольшим возрастом.

Важно: без `ORDER BY` порядок строк не гарантирован.
