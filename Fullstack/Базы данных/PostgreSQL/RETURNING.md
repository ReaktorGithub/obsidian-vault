`RETURNING` позволяет получить данные изменённых строк сразу после выполнения `INSERT`, `UPDATE`, `DELETE` или `MERGE`, не выполняя отдельный `SELECT`.

### INSERT

Получить созданную запись, включая автоматически сгенерированный `id`:

```
INSERT INTO users (name, age)
VALUES ('Олег', 30)
RETURNING id, name, age;
```

Результат:

|id|name|age|
|---|---|---|
|1|Олег|30|

### UPDATE

Получить обновлённые значения:

```
UPDATE users
SET age = 31
WHERE id = 1
RETURNING *;
```

`*` возвращает все столбцы изменённых строк.

### DELETE

Получить данные удалённых строк:

```
DELETE FROM users
WHERE age < 18
RETURNING id, name;
```

Несмотря на удаление записей, PostgreSQL возвращает их значения в результате запроса.

### RETURNING с выражениями

Можно возвращать не только столбцы, но и вычисляемые значения:

```
UPDATE products
SET price = price * 1.1
WHERE id = 1
RETURNING id, price AS new_price;
```

### Основные особенности

- `RETURNING` возвращает только строки, затронутые операцией.
- Можно использовать `*`, отдельные столбцы и выражения.
- Особенно полезен для получения автоматически сгенерированного `id` после `INSERT`.
- Если операция не затронула ни одной строки, результат будет пустым.

**Для собеседования:** `RETURNING` позволяет получить данные вставленных, обновлённых или удалённых строк непосредственно из запроса, избегая дополнительного `SELECT`.
