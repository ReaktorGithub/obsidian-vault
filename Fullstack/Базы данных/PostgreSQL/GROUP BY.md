`GROUP BY` — группирует строки с одинаковыми значениями в указанных столбцах. Часто используется вместе с агрегатными функциями.

Допустим, есть таблица `orders`:

|id|city|amount|
|---|---|---|
|1|Москва|1000|
|2|Тула|500|
|3|Москва|2000|
|4|Тула|1500|
|5|Москва|3000|

## Без GROUP BY

```
SELECT city, amount
FROM orders;
```

Результат — все строки исходной таблицы:

|city|amount|
|---|---|
|Москва|1000|
|Тула|500|
|Москва|2000|
|Тула|1500|
|Москва|3000|

## С GROUP BY

Посчитаем общую сумму заказов для каждого города:

```
SELECT city, SUM(amount) AS total
FROM orders
GROUP BY city;
```

Результат:

|city|total|
|---|---|
|Москва|6000|
|Тула|2000|

В чём разница?

- Без `GROUP BY` получаем отдельную строку для каждого заказа.
    
- С `GROUP BY city` объединяем заказы с одинаковым городом в группы и считаем сумму внутри каждой группы с помощью `SUM()`.
    

То есть пять заказов превратились в две строки — по одной на каждый город.

### Пример

```
SELECT city, COUNT(*) AS users_count
FROM users
GROUP BY city;
```

Группирует пользователей по городам и считает количество пользователей в каждом городе.

```
SELECT city,
       COUNT(*) AS users_count,
       AVG(age) AS average_age
FROM users
GROUP BY city;
```

Для каждого города выводит количество пользователей и их средний возраст.

### Группировка по нескольким столбцам

```
SELECT city, country, COUNT(*)
FROM users
GROUP BY city, country;
```

Создаёт группы по уникальным комбинациям города и страны.

### Фильтрация групп через HAVING

`WHERE` фильтрует строки до группировки, а `HAVING` — уже сформированные группы.

```
SELECT city, COUNT(*) AS users_count
FROM users
GROUP BY city
HAVING COUNT(*) > 10;
```

Возвращает только города, в которых больше 10 пользователей.

### GROUP BY + ORDER BY

```
SELECT city, COUNT(*) AS users_count
FROM users
GROUP BY city
ORDER BY users_count DESC;
```

Выводит города в порядке убывания количества пользователей.

Важно: если в `SELECT` есть столбец без агрегатной функции, он обычно должен присутствовать в `GROUP BY` или быть функционально зависимым от группируемых столбцов.
