`SERIAL` — псевдотип, который автоматически создаёт последовательность (`SEQUENCE`) и использует её для генерации числовых значений столбца.

```
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name TEXT
);
```

При добавлении записей `id` генерируется автоматически:

```
INSERT INTO users (name)
VALUES ('Олег'), ('Анна');
```

Результат:

|id|name|
|---|---|
|1|Олег|
|2|Анна|

Виды `SERIAL`:

- `SMALLSERIAL` — использует `SMALLINT`.
    
- `SERIAL` — использует `INTEGER`.
    
- `BIGSERIAL` — использует `BIGINT`.
    

Важно: `SERIAL` сам по себе не гарантирует уникальность. Для этого добавляют `PRIMARY KEY` или `UNIQUE`.

## CREATE SEQUENCE

`SEQUENCE` — отдельный объект базы данных, который генерирует последовательность чисел. Его можно создавать и настраивать вручную.

```
CREATE SEQUENCE user_id_seq
    START WITH 1
    INCREMENT BY 1;
```

Основные параметры:

- `START WITH` — начальное значение.
    
- `INCREMENT BY` — шаг изменения.
    
- `MINVALUE` / `MAXVALUE` — минимальное и максимальное значения.
    
- `CYCLE` — начинать сначала после достижения предела.
    
- `NO CYCLE` — не начинать сначала (по умолчанию).
    

### Использование последовательности

```
SELECT nextval('user_id_seq');
```

Каждый вызов `nextval()` возвращает следующее значение последовательности.

```
SELECT currval('user_id_seq');
```

Возвращает последнее значение, полученное через `nextval()` в текущей сессии.

```
SELECT setval('user_id_seq', 100);
```

Устанавливает текущее значение последовательности. При таком вызове следующий `nextval()` обычно вернёт `101`.

### Подключение последовательности к столбцу

```
CREATE SEQUENCE user_id_seq;

CREATE TABLE users (
    id INTEGER PRIMARY KEY DEFAULT nextval('user_id_seq'),
    name TEXT
);
```

Теперь `id` будет генерироваться автоматически.

## SERIAL vs IDENTITY

В современном PostgreSQL для новых таблиц часто рекомендуют `IDENTITY`:

```
CREATE TABLE users (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name TEXT
);
```

- `SERIAL` — удобное сокращение, использующее последовательность и `DEFAULT`.
    
- `IDENTITY` — стандартный SQL-механизм автоинкремента, встроенный в определение столбца.
    
- `SEQUENCE` — самостоятельный объект, который можно использовать напрямую или подключать к разным задачам.
    

Для собеседования: `SERIAL` автоматически создаёт последовательность для столбца, а `CREATE SEQUENCE` позволяет создать и настроить её вручную. Ни один из механизмов сам по себе не гарантирует отсутствие пропусков в нумерации: например, при откате транзакции выданные значения не возвращаются.
