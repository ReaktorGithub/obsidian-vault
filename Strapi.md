Strapi - это open-source headless CMS на Node.js, которая позволяет создавать и управлять контентом через админ-панель и предоставлять его фронтенду через API.

Например, в React-проекте Strapi может хранить статьи, изображения, категории и настройки страниц. Контент-менеджер добавляет статью в админке, Strapi сохраняет её в базе данных и предоставляет React-приложению через REST API или GraphQL.

Основные возможности:

- Content Types - создание сущностей, например Article, Product, Category, без написания всей CRUD-логики вручную.
    
- Admin Panel - управление контентом через веб-интерфейс.
    
- API - автоматическая генерация REST API, поддержка GraphQL через плагин.
    
- Roles & Permissions - настройка ролей и прав доступа.
    
- Media Library - хранение и управление изображениями и другими файлами.
    

Пример связки: React / Next.js → API Strapi → база данных PostgreSQL.

Отличие от обычного backend на NestJS в том, что Strapi уже предоставляет готовую CMS, админку и типовые операции с контентом. NestJS чаще используют, когда бизнес-логика и архитектура backend требуют более индивидуальной реализации.
