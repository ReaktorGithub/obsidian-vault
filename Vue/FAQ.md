## 1. Основы Vue

1. Что такое Vue.js?

Vue - прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов. Использует компонентный подход, реактивность и декларативное описание UI.

2. Чем Vue отличается от React?

Vue предоставляет готовые решения для шаблонов, директив и реактивности. React использует JSX и обычно требует дополнительных библиотек для роутинга и управления состоянием. В Vue есть встроенные механизмы реактивности, а в React состояние чаще организовано через хуки.

3. Что такое Single File Component (SFC)?

Это файл `.vue`, который обычно содержит три секции: `<template>` для разметки, `<script>` для логики и `<style>` для стилей.

4. Что такое Composition API?

API для организации логики компонентов с помощью функций `ref`, `reactive`, `computed`, `watch` и других. Позволяет группировать код по функциональности и повторно использовать логику через composables.

5. Чем Composition API отличается от Options API?

Options API разделяет код по секциям `data`, `methods`, `computed` и `watch`. Composition API позволяет группировать связанные данные и методы вместе, что удобнее для сложных компонентов и переиспользования логики.

6. Что такое `<script setup>`?

Синтаксический сахар для Composition API в SFC. Упрощает объявление реактивных переменных, функций и props, а также автоматически делает их доступными в шаблоне.

## 2. Реактивность

7. Что такое реактивность во Vue?

Это механизм, при котором Vue отслеживает зависимости от реактивных данных и обновляет связанные части интерфейса при изменениях.

8. Чем отличаются `ref` и `reactive`?

`ref` создает реактивную обертку для значения и подходит в том числе для примитивов. `reactive` создает реактивный Proxy объекта. В JavaScript значение `ref` читается и изменяется через `.value`, но в шаблоне верхнеуровневые refs обычно разворачиваются автоматически.

9. Чем `computed` отличается от `watch`?

`computed` вычисляет производное значение и кэширует результат до изменения зависимостей. `watch` запускает побочные эффекты при изменении отслеживаемых данных, например API-запросы.

10. Чем `watch` отличается от `watchEffect`?

`watch` явно указывает источники наблюдения и передает старое и новое значения. `watchEffect` автоматически отслеживает реактивные зависимости, которые читаются во время выполнения функции.

11. Как Vue отслеживает изменения объектов?

Во Vue 3 используется система Proxy для объектов и getter/setter-механизм внутри refs. При чтении собираются зависимости, а при изменении запускаются связанные эффекты и обновления интерфейса.

12. Почему изменение обычной переменной не обновляет шаблон?

Vue не отслеживает обычные переменные вне реактивной системы. Чтобы интерфейс обновлялся, нужно использовать реактивные источники, например `ref` или `reactive`.

## 3. Шаблоны и директивы

13. Что такое директивы Vue?

Директивы - специальные атрибуты с префиксом `v-`, которые управляют поведением DOM. Например, `v-if`, `v-for`, `v-model`, `v-bind` и `v-on`.

14. Чем отличаются `v-if` и `v-show`?

`v-if` создает и удаляет элемент из DOM. `v-show` оставляет элемент в DOM и переключает CSS-свойство `display`. `v-show` удобнее при частых переключениях.

15. Для чего нужен `key` в `v-for`?

`key` помогает Vue правильно сопоставлять элементы между обновлениями списка. Обычно используют уникальный стабильный ID, а не индекс массива, особенно если список изменяется.

16. Чем отличаются `v-bind` и `v-on`?

`v-bind` связывает атрибут или prop с выражением, сокращенная запись - `:`. `v-on` обрабатывает события, сокращенная запись - `@`.

17. Что такое `v-model`?

Двусторонняя связь между состоянием и элементом формы или компонентом. На обычном input она синхронизирует значение и события ввода, а на компоненте работает через prop `modelValue` и событие `update:modelValue` по умолчанию.

## 4. Компоненты

18. Как передавать данные между компонентами?

От родителя к дочернему компоненту данные передаются через props. От дочернего к родителю можно отправлять события через `emit`. Для общей логики используют provide/inject или хранилище состояния.

19. Что такое props?

Props - входные параметры компонента. Они передаются родителем, и дочерний компонент не должен напрямую изменять их. Для изменения данных обычно отправляют событие родителю.

20. Что такое `emit`?

Механизм отправки пользовательских событий из дочернего компонента родителю. Например, компонент кнопки может отправить событие `save`.

21. Что такое slots?

Slots позволяют передавать разметку от родителя внутрь дочернего компонента. Это делает компоненты гибкими и позволяет повторно использовать их с разным содержимым.

22. Что такое provide/inject?

Механизм передачи данных от компонента-предка любому компоненту-потомку без последовательной передачи props через каждый промежуточный компонент.

23. Что такое lifecycle hooks?

Это хуки жизненного цикла компонента. Например, `onMounted` вызывается после монтирования компонента, `onUpdated` - после обновления DOM, `onUnmounted` - после удаления компонента.

24. Где выполнять API-запросы в компоненте?

Часто запрос выполняют в `onMounted`, если данные нужны после монтирования. Для запросов, зависящих от параметров, используют `watch` или другие механизмы управления состоянием. Важно обрабатывать ошибки и отменять ненужные запросы при необходимости.

## 5. Управление состоянием

25. Что такое Pinia?

Pinia - официальная библиотека управления состоянием для Vue. Она позволяет создавать stores с состоянием, getters и actions, доступными разным компонентам.

26. Чем Pinia отличается от локального состояния компонента?

Локальное состояние принадлежит конкретному компоненту. Pinia используется для состояния, которое нужно разделять между компонентами или сохранять в общей модели приложения.

27. Что такое composable?

Composable - функция, которая использует Composition API для повторного использования логики. Обычно называется с префикса `use`, например `useAuth()` или `useFetch()`.

28. Чем composable отличается от Pinia store?

Composable повторно использует логику и может иметь собственное состояние. Pinia store предназначен для централизованного состояния приложения и предоставляет стандартные механизмы доступа к нему из разных компонентов.

## 6. Производительность

29. Как оптимизировать производительность Vue-приложения?

Использовать lazy loading компонентов и маршрутов, стабильные ключи списков, `computed` для производных данных, виртуализацию больших списков и избегать лишней реактивности для больших неизменяемых объектов.

30. Для чего нужен `defineAsyncComponent`?

Он позволяет загружать компонент асинхронно, например только при необходимости его отображения. Это помогает разделять код и уменьшать первоначальный бандл.

31. Что такое `nextTick`?

Функция, которая позволяет дождаться завершения следующего цикла обновления DOM после изменения реактивного состояния. Полезна, когда нужно получить обновленный DOM после изменения данных.

32. Зачем нужен `shallowRef`?

Он делает реактивным само значение ref, но не преобразует вложенные свойства объекта в глубокую реактивную структуру. Полезен для больших объектов, внешних библиотек и неизменяемых данных.

## 7. Vue Router и запросы

33. Что такое Vue Router?

Официальная библиотека маршрутизации Vue. Позволяет связывать URL с компонентами страниц, использовать динамические параметры, вложенные маршруты и навигационные guards.

34. Что такое navigation guards?

Функции, которые позволяют контролировать переходы между маршрутами. Например, можно проверять авторизацию перед открытием защищенной страницы.

35. Как работает lazy loading маршрутов?

Компонент маршрута импортируется динамически через `import()`. Сборщик может вынести его в отдельный chunk, который загрузится при переходе на маршрут.

36. Как организовать загрузку данных с API?

Вынести запросы в отдельный API-модуль или composable, хранить состояние загрузки и ошибок, обрабатывать ответы и при необходимости отменять устаревшие запросы. Для более сложного кэширования можно использовать TanStack Query для Vue.

## 8. Дополнительные вопросы уровня Middle/Senior

37. Что такое виртуальный DOM?

Это JavaScript-представление структуры интерфейса. Vue сравнивает новое представление с предыдущим и применяет необходимые изменения к реальному DOM.

38. Что такое `Teleport`?

Компонент, который позволяет отрисовывать содержимое в другом месте DOM, сохраняя связь с исходным компонентом. Часто используется для модальных окон и всплывающих панелей.

39. Что такое `KeepAlive`?

Компонент, который кэширует экземпляры динамических компонентов вместо их уничтожения при переключении. Позволяет сохранять их состояние.

40. Что такое SSR в Vue?

Server-Side Rendering - рендеринг HTML на сервере. Для Vue его часто реализуют с помощью Nuxt. Это может улучшить первоначальное отображение страницы и индексацию поисковыми системами.

41. Что такое hydration?

Процесс, при котором клиентский JavaScript подключается к HTML, заранее отрендеренному на сервере, и делает интерфейс интерактивным.

42. Что такое `markRaw`?

Функция, которая исключает объект из преобразования в реактивный Proxy. Применяется для объектов, которые не должны отслеживаться реактивной системой.

43. Что такое `defineProps` и `defineEmits`?

Компиляторные макросы для объявления входных props и событий компонента внутри `<script setup>`. Не требуют обычного импорта во Vue 3.

44. Что такое директива `v-memo`?

Она позволяет пропускать обновление определенной части шаблона, пока заданные зависимости не изменились. Полезна в отдельных сценариях оптимизации больших списков, но обычно не нужна без измеренной проблемы.

45. Как избежать утечек памяти в компонентах?

Очищать таймеры, подписки и обработчики событий, отменять ненужные запросы. Для реактивных watchers, созданных в стандартном контексте компонента, Vue обычно самостоятельно выполняет очистку при его размонтировании.
