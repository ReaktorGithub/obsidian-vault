**Программный модуль** — это часть конфигурации 1С, содержащая программный код на встроенном языке 1С. Используется для описания алгоритмов, обработки данных и реализации бизнес-логики.

Модули бывают общими, объектными, модульными формами и другими, в зависимости от места размещения и назначения.

Crtl+F1 - открыть синтекс помощник в контексте строки кода, на котором в данный момент установлен курсор.

Ctrl+F7 - проверка модуля на синтаксис

Оператор - выражение (одно действие), которое заканчивается точкой с запятой.

Переменная - именованный контейнер для хранения данных.

Правила объявления переменной:
- начинаться с буквы или _
- не должно содержать пробелов и спец символов
- первая буква большая
- если несколько слов, то каждое слово с большой буквы

Перем ИмяПеременной;
ИмяПеременной = Значение;
### Аналог console.log()

Сообщить("Hello world");

"Сообщить" - это процедура

Далее: запустить сеанс пользователя (F5)

### Полезные настройки

Сервис - настройки - модули - редактирование - автозамена - включить с подсказкой

Ctrl + пробел - автоматически дописать процедуру или показать всплывающее меню с вариантами

Там же: изменить цвет текущего идентификатора.

### Примитивные типы данных

- **Число** — целые и дробные значения. Например: `10`, `3.14`.
    
- **Строка** — текстовые данные. Например: `"Привет"`.
    
- **Булево** — логические значения `Истина` и `Ложь`.
    
- **Дата** — дата и время. Например: `Дата(2026, 11, 24)`.
    
- **Неопределено** — значение, которое не определено.
    
- **Null** — отсутствие значения, например при работе с запросами к БД.
    
## **Операторы**

- **Арифметические:** `+`, `-`, `*`, `/`, `%` — математические операции.
    
- **Сравнения:** `=`, `<>`, `<`, `>`, `<=`, `>=` — сравнение значений.
    
- **Логические:** `И`, `ИЛИ`, `НЕ` — логические операции.
    
- **Присваивание:** `=` — присвоение значения переменной.
    
- **Конкатенация:** `+` — объединение строк.
    
- **Условный оператор:** `Если ... Тогда ... Иначе ... КонецЕсли`.
    
- **Циклы:** `Для ... По ... Цикл`, `Пока ... Цикл`.

### Равенство и неравенство

- `=` — оператор равенства. Проверяет, равны ли два значения. Возвращает `Истина` или `Ложь`.
    
- `<>` — оператор неравенства. Проверяет, отличаются ли два значения. Возвращает `Истина` или `Ложь`.
    

```
Если Число = 10 Тогда
    Сообщить("Число равно 10");
КонецЕсли;

Если Число <> 10 Тогда
    Сообщить("Число не равно 10");
КонецЕсли;
```

**Важно:** в 1С `=` используется и для присваивания, и для сравнения. В контексте оператора присваивания значение записывается в переменную, а в условии сравниваются значения.

```
Число = 10; // Присваивание

Если Число = 10 Тогда // Сравнение
    ...
КонецЕсли;
```

### Тип()

`Тип()` — функция, возвращающая тип переданного значения. Используется для проверки типа данных переменной или выражения.

```
Значение = 10;

Сообщить(Тип(Значение)); // Число
```

Для проверки конкретного типа используется сравнение с `Тип("...")`:

```
Если Тип(Значение) = Тип("Строка") Тогда
    Сообщить("Это строка");
КонецЕсли;
```

### ТипЗнч()

`ТипЗнч()` — функция, возвращающая тип значения, переданного в качестве аргумента. Используется для определения фактического типа данных переменной или выражения.

```
Значение = 10;

Сообщить(ТипЗнч(Значение)); // Число
```

**Отличие от** `Тип()`**:** `ТипЗнч()` определяет тип конкретного значения, а `Тип()` используется для получения значения типа по его строковому представлению.

```
ТипЧисло = Тип("Число");
ФактическийТип = ТипЗнч(10);
```

## Условный оператор

- `Если ... Тогда ... Иначе ... КонецЕсли` — условный оператор, выполняющий определённый блок кода в зависимости от условия. Условие должно возвращать `Истина` или `Ложь`.

```
Если Возраст >= 18 Тогда
    Сообщить("Совершеннолетний");
Иначе
    Сообщить("Несовершеннолетний");
КонецЕсли;
```

- `ИначеЕсли` — проверяет дополнительное условие, если предыдущие условия не выполнились.

```
Если Балл >= 90 Тогда
    Оценка = 5;
ИначеЕсли Балл >= 70 Тогда
    Оценка = 4;
Иначе
    Оценка = 3;
КонецЕсли;
```

**Тернарный оператор** — краткая форма условного выражения в 1С:

```
Результат = ?(Условие, ЗначениеЕслиИстина, ЗначениеЕслиЛожь);
```

Пример:

```
Возраст = 20;
Статус = ?(Возраст >= 18, "Совершеннолетний", "Несовершеннолетний");
```

### Циклы

### **Цикл по условию —** `Пока ... Цикл`

Выполняется до тех пор, пока условие истинно. Количество итераций заранее неизвестно.

```
Счетчик = 0;

Пока Счетчик < 5 Цикл
    Счетчик = Счетчик + 1;
КонецЦикла;
```

### **Цикл по коллекции —** `Для Каждого ... Из ... Цикл`

Перебирает все элементы коллекции (массив, список, таблицу значений и т. д.).

```
Массив = Новый Массив;
Массив.Добавить("Apple");
Массив.Добавить("Banana");
Массив.Добавить("Orange");

Для Каждого Элемент Из Массив Цикл
    Сообщить(Элемент);
КонецЦикла;
```

Аналог в JavaScript: `for...of`.

### **Цикл по счётчику —** `Для ... По ... Цикл`

Выполняется заданное количество раз. Счётчик автоматически увеличивается на единицу.

```
Для Счетчик = 1 По 5 Цикл
    Сообщить(Счетчик);
КонецЦикла;
```

Аналог в JavaScript: классический `for`.

### **Управление циклами**

- `Прервать` — досрочно завершает цикл.
    
- `Продолжить` — пропускает текущую итерацию и переходит к следующей.

Если программа 1С попадает в бесконечный цикл, выполнение текущего потока не прекращается самостоятельно.

**Как остановить:**

- В режиме разработки можно попытаться прервать выполнение сочетанием `Ctrl + Break`
    
- Если прервать выполнение не удаётся, может потребоваться принудительно завершить процесс 1С через диспетчер задач.

## **Коллекции

**Коллекции** — объекты, предназначенные для хранения и группировки нескольких значений. Позволяют добавлять, удалять, перебирать и получать элементы.

### **Основные коллекции**

- **Массив** — упорядоченная коллекция элементов, доступ к которым осуществляется по индексу (начиная с 0).
    
- **Структура** — набор пар «ключ — значение». Ключи имеют строковые имена.
    
- **Соответствие** — коллекция пар «ключ — значение», где ключом может быть значение различных типов.
    
- **СписокЗначений** — коллекция значений с возможностью хранить дополнительные представления и пометки для каждого элемента.
    
- **ТаблицаЗначений** — двумерная коллекция, состоящая из строк и колонок. Позволяет сортировать, фильтровать и искать данные.
    

### **Примеры**

**Массив:**

```
Массив = Новый Массив;
Массив.Добавить("Apple");
Массив.Добавить("Banana");

Сообщить(Массив[0]); // Apple
```

**Структура:**

```
Структура = Новый Структура;
Структура.Вставить("Имя", "Олег");
Структура.Вставить("Возраст", 30);

Сообщить(Структура.Имя);
```

**Соответствие:**

```
Соответствие = Новый Соответствие;
Соответствие.Вставить("name", "Олег");
Соответствие.Вставить(10, "Числовой ключ");

Сообщить(Соответствие.Получить("name"));
```

### **Аналогии с JavaScript**

|1С|JavaScript|
|---|---|
|Массив|Array|
|Структура|Object|
|Соответствие|Map|
|СписокЗначений|Прямого аналога нет|
|ТаблицаЗначений|Прямого аналога нет|

**Важно:** коллекции в 1С не являются примитивными типами данных. Это объекты, которые создаются с помощью `Новый` и имеют собственные методы и свойства.
