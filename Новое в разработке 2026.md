Что нового в React 19

- Server Components стали production-ready и активно используются в server-first архитектуре.
- Server Actions — серверные функции можно вызывать прямо из компонентов и форм без отдельного REST API.
- Новый hook `useActionState()` для async form state и server actions.
- `useOptimistic()` — встроенные optimistic updates без ручного rollback boilerplate.
- `useFormStatus()` — доступ к pending/status формы без prop drilling.
- Новый `use()` hook:
    - чтение Promise прямо во время render;
    - интеграция с Suspense;
    - можно вызывать conditionally.
- `ref` теперь можно передавать как обычный prop — меньше нужды в `forwardRef`.
- Улучшены hydration errors — React показывает более понятные diff/error сообщения.
- Поддержка metadata прямо в компонентах:
    
    ```
    <title /><meta />
    ```
    
- Улучшенная работа со стилями, preload/preconnect и async scripts.
- React Compiler (React Forget):
    - автоматическая memoization;
    - меньше нужды в `useMemo/useCallback`.
- React движется в сторону:
    - server-first;
    - уменьшения `useEffect`;
    - async rendering;
    - streaming/Suspense architecture.

## Что нового в React 18

- Concurrent Rendering — React может прерывать и приоритизировать рендеринг для более отзывчивого UI.
- Automatic Batching — несколько state updates автоматически объединяются в один render.
- `createRoot()` — новый concurrent root API вместо старого `ReactDOM.render()`.
- `startTransition()` — возможность помечать обновления как non-urgent.
- `useTransition()` — управление pending state при transition updates.
- `useDeferredValue()` — откладывание тяжёлых обновлений для улучшения UX.
- Улучшенный `Suspense`:
    - SSR streaming;
    - data fetching integration;
    - async UI rendering.
- Streaming SSR — сервер может отправлять HTML частями.
- Selective Hydration — React гидрирует важные части страницы раньше остальных.
- Новый hook `useId()` — генерация стабильных id для SSR/CSR.
- Strict Mode стал строже:
    - двойной вызов lifecycle/effects в dev mode;
    - помогает находить side effects.
- Основа для React Server Components и future server-first архитектуры.
- Улучшения производительности для больших SPA и async rendering.
